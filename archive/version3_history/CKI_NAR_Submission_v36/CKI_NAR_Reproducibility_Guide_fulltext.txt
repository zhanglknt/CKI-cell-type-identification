2. CKI Algorithm Definition
CKI decomposes transcriptomic divergence into two components:
omega = k_f / k_n
where:
k_n  = JS(p_HK_A || p_HK_B)       ... baseline divergence rate
k_f  = JS(p_ID_A || p_ID_B)       ... functional divergence rate
and JS(P || Q) is the Jensen-Shannon divergence (base-2 logarithm, range [0, 1]):
M        = 0.5 * (P + Q)
JS(P||Q) = 0.5 * KL(P||M) + 0.5 * KL(Q||M)
where KL(P||M) = sum_i [ P_i * log2(P_i / M_i) ]  for P_i > 0
Both k_n and k_f use the same computational pipeline: (1) subset the pseudobulk expression vector to the relevant gene indices; (2) apply softmax normalization to convert expression values into a probability distribution:  p_i = exp(x_i) / sum_j exp(x_j); (3) compute JS divergence between the two resulting distributions. This internal consistency (same metric, same normalization, same underlying expression space) ensures omega is self-calibrated.

3. Gene Set Selection
3.1 Housekeeping Genes (for k_n)
In all reported analyses, housekeeping (HK) genes were loaded from
the HRT Atlas v1.0 reference (Hounkpe et al., NAR 2021) via the file
data/housekeeping/Human_Mouse_Common.csv (1,130 human-mouse conserved
HK genes; identical to cki/data/hrt_atlas.csv).

For each dataset, HK genes were loaded as follows:
  Tabula Muris (mouse):   HRT Atlas mouse genes (column 0),
  Tabula Sapiens (human): HRT Atlas human genes (column 1),
  TCGA (human):           HRT Atlas human genes (column 1),
  Siletti Brain (human):  HRT Atlas human genes (column 1).

The CKI package also supports data-driven auto-detection via
detect_housekeeping_genes() (detection rate > 0.9, CV < 30th
percentile, "combined" method; use_reference=False by default),
but this was NOT used in the reported analyses.
3.2 Identity Genes (for k_f)
Identity (functional) genes are defined as:
Default (CKI): top-2,000 highly variable genes (HVGs; Scanpy seurat flavor), with HK genes explicitly excluded to maintain k_n/k_f independence (adapted to min(2000, 0.8 * n_total_genes)).
Hybrid mode: per-pair k_n computed on the shared HK gene set (a single HK reference applied to all pairs, keeping k_n on a consistent scale across the atlas); per-pair k_f uses the top-200 differentially expressed genes (ranked by |mean_diff| between the two groups), excluding HK genes.
The default mode (global HVG 2,000) is used only for the Tabula Muris full pairwise matrix (03_full_matrix.py, 703 pairs, Fig. 2 heatmap). The hybrid mode (per-pair k_n with per-pair top-200 DE k_f) is used for all other reported analyses: Tabula Muris pilot analyses (calibration controls + validation, 02b_pilot_v2.py), Tabula Sapiens (human), TCGA, and the Siletti brain atlas. In every dataset, k_n is computed per pair on the shared HK gene set: a sensitivity analysis contrasting this per-pair estimator with a global-k_n variant (k_n computed once from the full gene-by-cell-type pseudobulk matrix) showed that brain k_n exhibits substantial cross-pair variability (CV = 92.89%) that is poorly captured by a global mean, and that the two estimators yield substantially different omega rankings (Spearman rho = 0.181; Supplementary Fig. S11). The parameter sweep (Supplementary Figure 1) confirmed that the identity-only configuration (w1 = 1.0, w2 = 0.0) achieves the best cell-type discrimination without external pathway databases.
4. Data Sources & Preprocessing
4.1 Tabula Muris (Mouse) — Result 2 (Fig. 2)
Dataset:    Tabula Muris FACS (Schaum et al., Nature 2018)
Source:     https://github.com/czbiohub-sf/tabula-muris (raw data; GEO accession GSE109774 provides the processed version used in this study)
Technology: SmartSeq2
Data used:  15,057 cells, 22,308 genes, 6 organs (Liver, Kidney, Spleen, Lung, Heart, Marrow)
Processing:
  1. Load per-tissue count matrices (FACS/tissue-counts.csv).
  2. Intersect to common gene set across all tissues.
  3. Normalize: sc.pp.normalize_total(target_sum=1e4), then log1p.
  4. Pseudobulk: mean expression per cell-type annotation.
  5. Filter: cell types with < 10 cells excluded.
  6. Compute per-pair k_n on the shared HK gene set for each cell-type pair.
  7. Compute per-pair k_f with top-200 DE genes (ranked by |mean_diff|, HK excluded).
  8. Bootstrap: n = 1,000 permutations, one-sided test (P = (count(ω_null ≥ ω_obs) + 1)/(B + 1)).
Controls: Six random-split comparisons (same cell population divided into two halves) tested baseline behavior (empirical baseline omega = 6.67, 95% bootstrap CI [4.24, 9.24], B = 10,000 resamples of the 6 control omega values; see Section 5.4 a for reproduction).
Total pairs: 703 cell-type pairs across 6 organs.
4.2 Tabula Sapiens (Human) — Result 3 (Fig. 3)
Dataset:    Tabula Sapiens (Jones et al., Science 2022)
Source:     https://github.com/czbiohub-sf/tabula-sapiens (raw data; CZ CELLxGENE Discover provides the processed version used in this study)
Technology: 10x Genomics (3′ and 5′ assays)
Data used:  108,136 cells (6 h5ad files total), 102 cell-type entries (99 of which passed the pairwise-analysis filters: at least 20 cells per entry and at least one donor with at least 10 cells; "unknown" annotations excluded), 6 organs (Liver, Kidney, Heart, Bone Marrow, Spleen, Lung)

  1. Load per-organ h5ad files (TS_{Organ}.h5ad; e.g., TS_Liver.h5ad, TS_Kidney.h5ad, etc.).

  6. Per-pair k_f: top-200 DE genes (ranked by absolute mean difference), HK genes excluded.
  7. Full pairwise omega computed for all 4,851 analyzed cell-type pairs (C(99, 2)).
Method comparison: Spearman rank correlation computed between CKI omega and four standard metrics on all 4,851 cell-type pairs: raw JS divergence (all genes), Spearman distance (1 - Spearman r), cosine distance (1 - cosine similarity), marker Jaccard distance (1 - intersection/union of top-200 marker genes per cell type). Classification AUC from cell-type pair classification task (same-type vs. different-type) computed with sklearn.metrics.roc_auc_score. Output: results/phase35_all_metrics_pairs.csv.
4.3 TCGA (Human Cancer) — Result 4 (Fig. 4)
Dataset:    TCGA Pan-Cancer (Hutter & Zenklusen, Cell 2018; Liu et al., Cell 2018)
Source:     UCSC Xena (https://xenabrowser.net/), file: tcga_RSEM_gene_tpm.gz
Data used:  3,596 samples (from 10,535 raw TCGA samples after filtering) across 5 cancer types: LUAD, LUSC, LIHC, KIRC, BRCA

  5. Per-pair k_n computed on the shared HK gene set for each sample pair.
  6. Per-pair k_f with top-200 DE genes (ranked by |mean_diff|).
  7. NN/TT ratio computed as mean(omega_NN) / mean(omega_TT) per cancer type.
Clinical stratification:
  LIHC Edmondson grade: G1 (n=39), G2 (n=133), G3 (n=105), G4 (n=11). Jonckheere-Terpstra trend test.
  BRCA PAM50 subtype: Basal-like (n=97), HER2 (n=55), LumA (n=224), LumB (n=123), Normal-like (n=7). Kruskal-Wallis test.
  LUAD mutation: EGFR (n=61), KRAS (n=120), WT (n=311). Kruskal-Wallis test.
4.4 Siletti Brain Atlas (Human) — Results 5 & 6 (Fig. 5 & 6)
Dataset:    Siletti et al. (Science 2023)
Source:     https://github.com/linnarsson-lab/snRNA_brain_atlas (raw data; CZ CELLxGENE Discover provides the processed version used in this study, collection ID as referenced in Siletti et al., Science 2023)
Technology: snRNA-seq (10x Genomics)
Data used:  888,263 non-neuronal nuclei (886,808 after filtering), 108 brain regions, 10 cell classes
Processing:
  1. Load Nonneurons.h5ad in backed mode (backed='r') for memory efficiency.
  2. Map gene symbols from var["Gene"]; match HK genes from HRT Atlas (1,115 of 1,130 human genes matched to the Siletti gene annotation).
  3. Group by (cell_type, brain_region). Filter groups with < 20 nuclei; require >= 50 nuclei per region.
  4. Build pseudobulk vectors: cell-count-weighted means of per-library (10x sample) mean expression vectors per (ct, region) group, then normalize_total (target_sum=1e4) and log1p at the pseudobulk level.
  5. Compute omega for all same-cell-type cross-region pairs (31,764 pairs total).
  6. Organize omega values per cell type and per region pair.
Cross-organ conservation (Fig. 5): Subset of 59 same-cell-type cross-organ pairs from Tabula Sapiens data. Ranked by mean omega per cell type.
Migration detection model (multiplicative):
For each (cell_type, region_pair) combination:
expected_omega = mu_ct * mu_pair / mu_grand
where mu_ct = cell type’s global mean omega, mu_pair = region pair’s mean omega, mu_grand = global mean over all 31,764 pairs (32.56).
residual = observed_omega / expected_omega
Confidence tiers:
  Strong:   residual < 0.3, omega < 15, lowest omega in region pair.
  Moderate: residual < 0.5, omega < 25.
  Weak:     residual < 0.75, omega < 35.
5. Statistical Testing
5.1 Bootstrap Permutation Test
For each cell-type pair comparison, the null hypothesis H0: no functional divergence beyond baseline is tested via permutation:
  1. Pool all cells from groups A and B.
  2. For each of B iterations (B = 1,000 for all datasets):
     a. Randomly permute cell labels.
     b. Split into two groups of original sizes.
     c. Recompute pseudobulks and omega.
  3. Null distribution = {omega_perm[1], ..., omega_perm[B]}.
  4. P-value (one-sided permutation test):
p = (count(omega_null >= omega_obs) + 1) / (B + 1)
  5. Effect size: SES = (omega_obs - mean_null) / std_null.
  6. Null-distribution reference values: the one-sided critical value at alpha=0.05 is percentile(null, 95); omega_obs above this value rejects H0. The interval [percentile(null, 2.5), percentile(null, 97.5)] is the central 95% range of the null distribution (descriptive only) and is NOT a confidence interval for omega itself. Confidence intervals for omega point estimates are computed separately by pair-level resampling (Section 5.3b).
5.2 Notes on Execution
Benjamini-Hochberg FDR correction is applied to the bootstrap P-values within each dataset (group-level tests: m = 10 for brain, 17 for human, 15 for mouse, 5 for TCGA). The q_value column in the bootstrap output CSV files (tcga_bootstrap_results.csv, human_bootstrap_results.csv, brain_bootstrap_results.csv) provides the BH-adjusted P-value. The BH procedure is implemented in cki/bootstrap.py:benjamini_hochberg(). For the brain per-pair migration screen, FDR correction is applied across all m = 31,764 region pairs under the block-shuffle null (Section 5.3c); the corresponding per-pair BH-adjusted P-values are in brain_bs_null_results.csv (column q_fdr), summarized in brain_bs_null_fdr_manifest.json.
5.3 Phase B Statistical Upgrades
Three additional statistical analyses were performed to address reviewer concerns (Phase B):

  a. Adaptive permutation analysis (C-S1):
     Script: notebooks/09_phaseB_statistical_upgrades.py
     Verified that B=1,000 is sufficient because bootstrap tests are at the cell-type level (10 brain, 17 human, 15 mouse), not the pair level. The minimum resolvable P-value (1/1001 = 9.99e-4) is well below the BH threshold for the top-ranked test in each dataset.

  b. Bootstrap confidence intervals (C-S2):
     Script: notebooks/09_phaseB_statistical_upgrades.py
     95% CIs computed by pair-level resampling (B=10,000) for all key omega estimates. Output: results/phaseB_bootstrap_cis.csv.

  c. Block-shuffle permutation null for the residual model (C-S3):
     Scripts: notebooks/08d_brain_blockshuffle_null.py, notebooks/08e_brain_blockshuffle_results.py
     10x Chromium libraries (sample_id) were treated as blocks, and the sample-to-region assignment was randomly permuted across libraries (preserving the observed per-region library-count structure); region pseudobulks, all 31,764 pair omega values, and multiplicative residuals were then recomputed. B = 1,000 permutations (minimum resolvable P = 1/1,001 = 9.99e-4). Per-pair empirical P-values use the one-sided lower-tail formula P = (count(omega_null <= omega_obs) + 1)/(B + 1), the appropriate direction because migration candidates are defined by anomalously low omega. Benjamini-Hochberg FDR was applied across all m = 31,764 pairs: no pair reached q < 0.05 (minimum q = 0.949). At this multiplicity q < 0.05 is unattainable at B = 1,000 regardless of the data (the BH threshold for the smallest ordered P-value, 0.05/31,764 = 1.6e-6, is roughly 600-fold below the P-value floor; resolving it would require B ~ 6e5 permutations), so the FDR outcome reflects permutation resolution rather than evidence against the candidates. Among the 55 Strong-tier candidates, 37 had raw P < 0.05 and are reported as hypothesis-generating signals; interpretation is restricted to the predefined Strong tier because per-signal tests are not independent. An earlier per-pair cell-label shuffle implementation of this test was anti-conservative (36.3% of pairs at the P-value floor) because it ignored the block structure of the experiment; the block-shuffle null rectifies this. A companion cell-type-level test (whether regional structure significantly raises a cell type's mean omega; one-sided upper-tail P across the same B = 1,000 permutations) is output in brain_bs_null_ct_test.csv. Output: results/brain_bs_null_observed_pairs.csv, results/brain_bs_null_results.csv, results/brain_bs_null_ct_test.csv, results/brain_bs_null_summary.txt, results/brain_bs_null_fdr_manifest.json.

  d. Omega distribution characterization (C-S5):
     Script: notebooks/09_phaseB_statistical_upgrades.py
     Computed skewness, kurtosis, and normality tests (Shapiro-Wilk, D'Agostino-Pearson) for all datasets. All omega distributions are right-skewed and non-normal. SES reported as descriptive measure. Output: results/phaseB_omega_distribution.json.

  a. Calibrated omega normalization (C-M1):

     Script: notebooks/09c_phaseC_methodological.py

     Script: notebooks/09c_phaseC_methodological.py
