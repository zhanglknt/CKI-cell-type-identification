P33: 2. CKI Algorithm Definition

P34: CKI decomposes transcriptomic divergence into two components:

P35: omega = k_f / k_n

P36: where:

P37: k_n  = JS(p_HK_A || p_HK_B)       ... baseline divergence rate

P38: k_f  = JS(p_ID_A || p_ID_B)       ... functional divergence rate

P39: and JS(P || Q) is the Jensen-Shannon divergence (base-2 logarithm, range [0, 1]):

P40: M        = 0.5 * (P + Q)

P41: JS(P||Q) = 0.5 * KL(P||M) + 0.5 * KL(Q||M)

P42: where KL(P||M) = sum_i [ P_i * log2(P_i / M_i) ]  for P_i > 0

P43: Both k_n and k_f use the same computational pipeline: (1) subset the pseudobulk expression vector to the relevant gene indices; (2) apply softmax normalization to convert expression values into a probability distribution:  p_i = exp(x_i) / sum_j exp(x_j); (3) compute JS divergence between the two resulting distributions. This internal consistency (same metric, same normalization, same underlying expression space) ensures omega is self-calibrated.

P44: 3. Gene Set Selection

P45: 3.1 Housekeeping Genes (for k_n)

P46: In all analyses, housekeeping (HK) genes were auto-detected using

P47: the combined criterion: detection rate > 0.9 AND coefficient of

P48: variation (CV) < 30th percentile (intersection of both criteria).

P49: The HRT Atlas v1.0 reference set (1,130 human-mouse conserved HK

P50: genes) is available as an optional enhancement via use_reference=True,

P51: but was NOT used in the reported analyses (use_reference=False).

P53: CKI function: detect_housekeeping_genes(adata, method="combined",

P54:   detection_rate=0.9, cv_percentile=0.3, use_reference=False)

P56: This data-driven approach ensures that HK genes are dataset-specific

P57: and reflect the actual technical noise floor of each experiment,

P58: rather than relying on a static reference that may not match the

P59: platform or annotation of the current data.

P60: 3.2 Identity Genes (for k_f)

P61: Identity (functional) genes are defined as:

P62: Default (CKI): top-2,000 highly variable genes (HVGs; Scanpy seurat flavor), with HK genes explicitly excluded to maintain k_n/k_f independence (adapted to min(2000, 0.8 * n_total_genes)).

P63: Hybrid mode: global k_n computed once with shared HK gene set; per-pair k_f uses the top-200 differentially expressed genes (ranked by |mean_diff| between the two groups), excluding HK genes.

P64: The default mode (global HVG 2,000) is used for Tabula Muris (mouse). The hybrid mode is used for Tabula Sapiens (human), TCGA, and brain atlas analyses to give each cell-type pair the most informative identity genes while keeping all pairs on a common k_n scale. The parameter sweep (Supplementary Figure 1) confirmed that the identity-only configuration (w1 = 1.0, w2 = 0.0) achieves the best cell-type discrimination without external pathway databases.

P65: 4. Data Sources & Preprocessing

P66: 4.1 Tabula Muris (Mouse) — Result 2 (Fig. 2)

P67: Dataset:    Tabula Muris FACS (Schaum et al., Nature 2018)

P68: Source:     https://github.com/czbiohub-sf/tabula-muris

P69: Technology: SmartSeq2

P70: Data used:  15,057 cells, 22,308 genes, 6 organs (Liver, Kidney, Spleen, Lung, Heart, Marrow)

P71: Processing:

P72:   1. Load per-tissue count matrices (FACS/tissue-counts.csv).

P73:   2. Intersect to common gene set across all tissues.

P74:   3. Normalize: sc.pp.normalize_total(target_sum=1e4), then log1p.

P75:   4. Pseudobulk: mean expression per cell-type annotation.

P76:   5. Filter: cell types with < 10 cells excluded.

P77:   6. Compute global k_n on all cell-type pseudobulks (shared HK set).

P78:   7. Compute per-pair k_f with global HVG set (2,000 genes, HK excluded).

P79:   8. Bootstrap: n = 500 permutations, absolute-deviation test.

P80: Controls: Six random-split comparisons (same cell population divided into two halves) tested neutral behavior (omega ~ 1).

P81: Total pairs: 703 cell-type pairs across 6 organs.

P82: 4.2 Tabula Sapiens (Human) — Result 3 (Fig. 3)

P83: Dataset:    Tabula Sapiens (Jones et al., Science 2022)

P84: Source:     https://github.com/czbiohub-sf/tabula-sapiens

P85: Technology: 10x Genomics (3′ and 5′ assays)

P86: Data used:  108,136 cells (6 h5ad files total), 102 cell-type entries, 6 organs (Liver, Kidney, Heart, Bone Marrow, Spleen, Lung)

P87: Processing:

P88:   1. Load per-organ h5ad files (TS_{Organ}.h5ad; e.g., TS_Liver.h5ad, TS_Kidney.h5ad, etc.).

P89:   2. Intersect to common gene set across all 6 organs.

P90:   3. Within each organ: filter cells with < 500 genes, then normalize: sc.pp.normalize_total(target_sum=1e4), log1p.

P91:   4. Pseudobulk: mean expression per cell_type_ontology_term_id.

P92:   5. Global k_n: JS divergence on full pseudobulk matrix with shared HK set.

P93:   6. Per-pair k_f: top-200 DE genes (ranked by absolute mean difference), HK genes excluded.

P94:   7. Full pairwise omega computed for all 5,151 cell-type pairs.

P95: Method comparison: Spearman rank correlation computed between CKI omega and four standard metrics on all 4,851 pairs: raw JS divergence (all genes), Spearman distance (1 - Spearman r), cosine distance (1 - cosine similarity), marker Jaccard distance (1 - intersection/union of top-200 marker genes per cell type). Classification AUC from cell-type pair classification task (same-type vs. different-type) computed with sklearn.metrics.roc_auc_score.

P96: 4.3 TCGA (Human Cancer) — Result 4 (Fig. 4)

P97: Dataset:    TCGA Pan-Cancer (Hutter & Zenklusen, Cell 2018; Liu et al., Cell 2018)

P98: Source:     UCSC Xena (https://xenabrowser.net/), file: tcga_RSEM_gene_tpm.gz

P99: Data used:  3,596 samples (from 10,535 raw TCGA samples after filtering) across 5 cancer types: LUAD, LUSC, LIHC, KIRC, BRCA

P100: Processing:

P101:   1. Filter: gene-level mean expression > 1 TPM within each cancer type (per-cancer independent filtering).

P102:   2. log2(TPM + 0.001) transformation.

P103:   3. Pseudobulk: mean expression per sample.

P104:   4. Sample pairs drawn from: tumor-tumor (TT), normal-normal (NN), tumor-normal (TN). Maximum 2,000 random TT and TN pairs each.

P105:   5. Global k_n computed once per cancer type using shared HK genes.

P106:   6. Per-pair k_f with top-200 DE genes (ranked by |mean_diff|).

P107:   7. NN/TT ratio computed as mean(omega_NN) / mean(omega_TT) per cancer type.

P108: Clinical stratification:

P109:   LIHC Edmondson grade: G1 (n=39), G2 (n=133), G3 (n=105), G4 (n=11). Jonckheere-Terpstra trend test.

P110:   BRCA PAM50 subtype: Basal-like (n=97), HER2 (n=55), LumA (n=224), LumB (n=123), Normal-like (n=7). Kruskal-Wallis test.

P111:   LUAD mutation: EGFR (n=61), KRAS (n=120), WT (n=311). Kruskal-Wallis test.

P112: 4.4 Siletti Brain Atlas (Human) — Results 5 & 6 (Fig. 5 & 6)

P113: Dataset:    Siletti et al. (Science 2023)

P114: Source:     https://github.com/linnarsson-lab/snRNA_brain_atlas

P115: Technology: snRNA-seq (10x Genomics)

P116: Data used:  888,263 non-neuronal nuclei, 108 brain regions, 10 cell classes

P117: Processing:

P118:   1. Load Nonneurons.h5ad in backed mode (backed='r') for memory efficiency.

P119:   2. Map gene symbols from var["Gene"]; match HK genes from HRT Atlas (1,130 human genes) to gene symbol column.

P120:   3. Group by (cell_type, brain_region). Filter groups with < 20 nuclei.

P121:   4. Build pseudobulk vectors: raw count means per (ct, region) group, then normalize_total (target_sum=1e4) and log1p at the pseudobulk level.

P122:   5. Compute omega for all same-cell-type cross-region pairs (31,764 pairs total).

P123:   6. Organize omega values per cell type and per region pair.

P124: Cross-organ conservation (Fig. 5): Subset of 60 same-cell-type cross-organ pairs from Tabula Sapiens data. Ranked by mean omega per cell type.

P125: Migration detection model (multiplicative):

P126: For each (cell_type, region_pair) combination:

P127: expected_omega = mu_ct * mu_pair / mu_grand

P128: where mu_ct = cell type’s global mean omega, mu_pair = region pair’s mean omega, mu_grand = global mean (8.01).

P129: residual = observed_omega / expected_omega

P130: Confidence tiers:

P131:   Strong:   residual < 0.3, omega < 15, lowest omega in region pair.

P132:   Moderate: residual < 0.5, omega < 25.

P133:   Weak:     residual < 0.75, omega < 35.

P134: 5. Statistical Testing

P135: 5.1 Bootstrap Permutation Test

P136: For each cell-type pair comparison, the null hypothesis H0: omega = 1 (no selective remodeling) is tested via permutation:

P137:   1. Pool all cells from groups A and B.

P138:   2. For each of B iterations (B = 500 mouse, 1000 human, 100 TCGA, 100 brain):

P139:      a. Randomly permute cell labels.

P140:      b. Split into two groups of original sizes.

P141:      c. Recompute pseudobulks and omega.

P142:   3. Null distribution = {omega_perm[1], ..., omega_perm[B]}.

P143:   4. P-value (absolute deviation from ω = 1):

P144: p = (count(|omega_null - 1| >= |omega_obs - 1|) + 1) / (B + 1)

P145:   5. Effect size: Cohen’s d = (omega_obs - mean_null) / std_null.

P146:   6. Test critical values at alpha=0.05: [percentile(null, 2.5), percentile(null, 97.5)]. Note: these are permutation-based test critical values for rejecting H0, NOT confidence intervals for omega itself.

P147: 5.2 Notes on Execution

P148: Multiple testing correction (Benjamini-Hochberg FDR) is NOT systematically applied in the current analyses: all reported P-values and significance thresholds use raw (uncorrected) bootstrap P-values. This applies uniformly to the manuscript figures and the code repository (notebooks/).
