CKI 使用指南

细胞状态动力学指数 — 从数据到生物学洞察
A visual reference for practitioners
v1.0
1核心流程
输入 → 分类 → 分化 → 输出
01
输入数据
Input
  • 基因表达矩阵
  • 管家基因自动检测（检出率+CV过滤）
  • 身份基因自动检测（HVG，排除HK）
02
基因分类
Classify
  • 管家基因 HK（中性参考）
  • 身份基因（功能标记）
  • 逐基因 JS 散度（校准）
03
计算分化
Compute
  • HK → k_n（中性分化）
  • Identity → k_f（功能分化）
  • Bootstrap CI（不确定性估计）
04
输出 ω
Output
  • ω = k_f / k_n
  • 统计显著性（P值、FDR）
  • 生物学解释（选择压力）
2解读 ω
ω = k_f / k_n — 解读指南
ω = k_f / k_n
ω < 0.5
收敛 / 净化选择 — 转录组均质化
ω ≈ 0.5–1.5
中性范围 — 无方向性选择
ω > 1.5
分化 / 正向选择 — 转录组重塑
k_f = 身份基因的 Jensen-Shannon 散度
k_n = 管家基因的 Jensen-Shannon 散度（中性参考）
ω < 1 = 转录组收敛（净化选择）
ω > 1 = 转录组分化（正向选择）
