# 统计学审稿报告 — CKI v12

## 评分: 5/10

**审稿维度：** 生物统计学（Bootstrap检验、多重检验校正、效应量性质、样本量与功效、分布假设、相关性分析、分类阈值）

---

## 1. Critical Issues（阻断发表的问题）

### 1.1 完全缺失的多重检验校正策略

稿件 Methods 部分明确声明：_"For human, TCGA, and brain analyses, standard statistical tests were applied without multiple-testing correction; all reported P-values are raw, uncorrected values."_ 这是本文最严重的统计学缺陷。

- **脑区分析涉及 31,764 对比较**。即使每个比较都将名义 α = 0.05 作为显著性阈值，预期会有约 1,588 个假阳性。稿件使用基于经验百分位数的乘法残差阈值（Strong: 第 1 百分位，Moderate: 第 5 百分位，Weak: 第 25 百分位）作为过滤标准，而非正式的多重检验校正（如 BH-FDR 或 Bonferroni）。残差模型本身不是假设检验，只是排序工具。
- **TCGA 分析**中 5 种癌症类型涉及数百对肿瘤-肿瘤比较，同样未校正。
- 仅校准阶段（n = 6 对照）报告了 bootstrap P 值，因为对照数量极少。但 4,851 对 Tabula Sapiens 的比较、31,764 对脑区的比较以及数百对 TCGA 的比较均未校正多重性。
- **BH-FDR 在通篇稿件中从头至尾均未实施。** 声称有 FDR 校正的说法如果出现在投稿信中，亦无法在方法学描述中得到证实。

### 1.2 Bootstrap P 值计算中的对称性假设

稿件的 bootstrap 检验公式为：

```
Empirical P = (count(|ω_null - 1| >= |ω_obs - 1|) + 1) / (B + 1)
```

此公式假定零分布在 ω = 1 附近对称。但稿件本身就指出：_"The empirical ω distribution is right-skewed (median 13.68 vs. mean 14.12 for Tabula Sapiens)."_

- 右侧偏态的分布使得基于绝对值偏差的双侧检验无效——如果 Bootstrap 零分布本身严重右偏，双侧检验的上下尾部概率是不等的。
- 此外，Bootstrap 零分布锚定于 ω = 1，而相同的 6 个校准对照产生的经验均值为 ω = 1.54。使用 |ω_null − 1| 作为检验统计量隐含地假定真实的零 ω 等于 1，但数据本身表明并非如此。
- **建议解决方案：** 改用 ω_obs 在 Bootstrap 零分布中的分位数作为双侧 P 值，而不对称地锚定于 ω = 1。或者直接使用排列零分位数方法（如 P = 2 × min(proportion above, proportion below) × B / (B+1)，加上伪计数校正）。

## 2. Major Issues（需要重大修改）

### 2.1 Bootstrap ��抽样次数（B = 500）不足

稿件使用 B = 500 次排列进行校准。通常：
- B = 500 时的最小可达到 P 值为 1/501 ≈ 0.002。若需声明 P < 0.001，则要求 B ≥ 1,000。
- 以 1,000 次重抽样为标准的 Monte Carlo 标准误在尾部较低。对于一个方法学论文（NAR），B = 1,000–10,000 是本领域的标准做法。
- 稿件的 Methods 部分有重复文字："B = 500 for mouse calibration and exploratory analyses; B = 500 for mouse calibration"——疑似书写错误。稿件其它地方提到 _"Bootstrap inference uses B = 500 for mouse calibration"_，但未提及具体数字。投稿信和复现指南均未澄清主分析中 B 的取值。

### 2.2 零假设的定义不够精确

排列过程是：汇集两群所有细胞，随机重新分配各细胞至原始大小的分组，重新计算伪散装向量和 ω_null。该过程检验的零假设是 _"两个群体在表达模式上可互换"_。但：

- 真实的无效应假设应该是 "k_f / k_n = 1"（即功能分化等于基线变异）。鉴于排列操作会打乱管家基因和特性基因，它检验的是一个更强且不够精确的假设：群体标签对完整表达矩阵无影响。
- 校准结果 ω = 1.54（而非 1.00）证实了该排列检验并不是对一个精确定义的零假设的检验。虽然作者承认了这一偏移，但他们并未为排列程序推导出形式上的零分布。

### 2.3 ω 的分布特性与方差结构讨论不足

作为两个 JS 散度的比值（k_n ∈ [0, 1]，k_f ∈ [0, 1]），ω 的性质涉及比例统计量。但稿件未讨论以下内容：

- **当 k_n → 0 时的不稳定性。** 稿件指出 k_n 的中位数为 0.034，范围为 0.0018–0.221。在 k_n 极小的情况下，k_n 的微小变化即可导致 ω 的巨大变化。Fieller 定理或 delta 方法可以提供 ω 的置信区间，但均未使用。
- **ω 的方差与样本量的关系。** 稿件未讨论ω的标准误如何随每个群体的细胞数量变化。对于每个区域-细胞类型组合仅含约 20–100 个细胞的脑区分析，这尤为值得关注。
- **右偏态。** 虽然指出分布是右侧偏态的并使用了非参数检验，但在解释均值与中位数对比结果时，未充分讨论偏态对尾部的影响。

### 2.4 Tabula Sapiens 样本量的误解

稿件声称 Tabula Sapiens 有 108,136 个细胞和 4,851 对比较。但实际上：
- 99 个细胞类型条目跨越 6 个器官，导致 99×98/2 = 4,851 对成对比较——但**这些并非独立**。同一个肾脏巨噬细胞出现在与其它 98 种细胞类型的 98 次比较中。
- 这种_对偶_结构意味着每对比较共享一个群体；标准独立假设不成立。脑区数据中的 31,764 次比较同样存在此问题。
- 解决思路：使用混合效应模型，以细胞类型作为随机效应，或适当调整标准误。

### 2.5 独立性与多重检验的混淆（人类数据分析）

对于人类数据（4,851 对），稿件报告：

_"CKI ω was negatively correlated with all four standard metrics (Spearman ρ = -0.57 to -0.38, all P < 0.001)"_

这些 P 值对应的 5 个不同度量中 4 对成对比较，共计 10 次独立检验。未应用多重检验校正。但这里的主要问题不是校正——更重要的是，相关性是**中等负相关**（ρ = −0.38 to −0.57），并非独立（独立意味着 ρ ≈ 0）。声称 CKI 捕捉到 _"独立的"_ 信息维度，夸大了实际情况。负相关性为中等强度，意味着并非正交。

### 2.6 Spearman 相关性未报告置信区间

稿件中所有 Spearman ρ 值均只报告了点估计值和关联 P 值。未提供 95% 置信区间。对于关键的声明，如：
- _"ω was negatively correlated with all four standard metrics (ρ = −0.57 to −0.38)"_
- _"No agreement with standard metrics (ρ = −0.40 to +0.02, n = 60 pairs)"_（跨器官分析）

这些 CI（可通过 Bootstrap 或 Fisher z 变换获得）对评估结论的精度至关重要——尤其是对于 n = 60 对的跨器官比较。

## 3. Minor Issues（建议修改）

### 3.1 乘法残差阈值缺乏正式校准

Strong/Moderate/Weak 阈值（残差 < 0.3 / < 0.5 / < 0.75）是基于经验百分位数而非正式统计推断：

- 它们对应的是观测分布的第 1、5、25 百分位——本质上是数据驱动的离群值检测，而非假设检验。
- 作者指出，基于排列的阈值（补充图 S5）产生了定性一致但不完全相同的截断值。应当系统地量化这些阈值对排列策略的敏感性，而不仅仅是在补充材料中提及。

**建议：** 报告采用两种方法的分类一致性（例如 Cohen's κ），使读者能够评估基于经验百分位数方法引入的不确定性。

### 3.2 JS 散度中自然对数与以 2 为底对数的不一致性

稿件声明 _"JS divergence uses the natural logarithm"_，但补充说明 1.1 将 JS 散度定义为以 2 为底的对数（log2）。另外，补充说明 1.1 指出 JS ∈ [0, 1] 当使用以 2 为底的对数时成立，但若使用自然对数，边界上限为 ln(2) ≈ 0.693。稿件正文与补充材料之间存在不一致性。

此项不一致不影响 ω 本身（因为是比值），但会影响 k_n 和 k_f 的绝对值。作者应在正文与补充材料中统一对数底数的说明。

### 3.3 样品间异方差性未处理

对于脑区分析，每个（区域，细胞类型）组合包含不同数量的细胞核（通常 20–100 个）。在 JS 散度计算中，均将该不均匀的精度处理为等权重的。较小的分组具有较高的抽样方差，但未进行加权或方差稳定化处理。

### 3.4 校准研究（n = 6）的统计功效严重不足

TOST 等价性检验使用了 6 个对照组和等价边界 [0.67, 1.50]，未能确认严格的等价性。这明确表明——
- 校准研究的统计功效极低（需要 n ≫ 6）。
- ω = 1 的零假设缺乏经验支持。
- 作者将其归因为 _"保守地使_ _k_n 估计值偏低"_ 的操作偏倚，但并未探索备选的估计量或校正。

**建议：** 在 n ≥ 30 个对照组上进行更大规模的校准（可能来自多个数据集），以更可靠地估计真实的操作零值。

### 3.5 符号表示令人困惑

_"Cohen's d = (ω_obs - mean(ω_null)) / sd(ω_null)"_

该公式计算的是排列检验中观测值相对于零均值的标准化偏差。虽然与 Cohen's d 的公式相同，但它并非检验两组均值之差，而是评估观测值相对于零分布均值的位置。称为 _"标准化效应量（permutation-based）"_ 会比称其为 Cohen's d 更少引起歧义，以避免与经典的双样本 Cohen's d 混淆。

### 3.6 缺失的统计方法：配对肿瘤-正常分析

配对肿瘤-正常的比较中仅有 n = 2–5 名患者，作者也明确承认限制了统计功效。但计算了 Mann-Whitney U 检验（配对 vs. 未配对比较），其中 5 种癌症类型中有 4 种不显著。对于 n ≤ 5 的情况，Mann-Whitney 检验可能存在偏差或无法达到 α = 0.05 下的显著性。此处使用 Wilcoxon 符号秩检验会更加合适。

### 3.7 伪散装聚合中的信息损失

_"Pseudobulk averaging discards within-population heterogeneity... The extent of information loss has not been formally quantified."_ 作者诚实地指出了这一点，但应运用统计方法更直接地量化和解决该问题——例如，比较伪散装 ω 值与基于每个细胞的群内 JS 散度的备选指标。这偏离了方法的核心贡献，因此列为 Minor issue。

## 4. 统计方法亮点

尽管存在上述问题，稿件在以下方面表现出较强的统计素养：

1. **非参数检验的使用得当。** 在 ω 分布偏态的情况下，选择 Spearman ρ、Kruskal-Wallis、Mann-Whitney 和 Jonckheere-Terpstra 是合适的，展示了良好的统计判断力。趋势检验（Jonckheere-Terpstra）在有序临床分级中的使用尤为出色。

2. **效应量与 P 值并重报告。** 稿件报告了 Cohen's d（排列检验）、ε²（Kruskal-Wallis）、秩双序列相关性（Mann-Whitney）以及 AUC 的 Bootstrap 置信区间。这种超越显著性检验、强调效应大小的做法堪称典范。

3. **ω 分布偏态的透明性。** 作者明确报告了 ω 分布的右偏态，并据此调整了统计方法（使用中位数而非均值，使用非参数检验）。许多稿件会掩盖这种分布特征。

4. **稳健性分析和敏感性分析良好。** 稿件包含了多种敏感性分析：管家基因集大小扫描（CV < 13%）、HVG 计数扫描（r > 0.97）、以 2,000 个 HVG vs. 4,000 个 HVG 的比较验证 ω，以及单组分 vs. 多组分 k_f 的验证（最优的恒等-唯一配置）。这体现了严谨的方法论。

5. **OPCs 作为阴性对照。** 在脑区分析中，将少突胶质前体细胞（OPCs）——已知迁移能力最强的 CNS 细胞——作为阴性对照，其 0/5,671 强信号的结果强有力地验证了乘法残差模型并非仅仅检测细胞运动性。这是统计方法开发中利用已知生物学对计算方法进行验证的一个巧妙实例。

6. **明确说明局限性。** 作者对以下内容的开放性讨论值得称赞：仅使用伪散装水平、操作性的管家基因定义、TCGA 中缺乏细胞类型去卷积、校准研究样本量小、以及操作零值与 1 之间存在偏差。这种透明度值得保持。

7. **残差模型的统计直觉是合理的。** 使用乘法模型（μ_ct × μ_pair / μ_grand）将全局均值、细胞类型边际均值和区域对边际效应分离，是检测相互作用效应的标准方法。虽然是基于经验百分位数的阈值设定，但概念设计在统计上是合理的。

## 5. 总体建议

**拒绝，鼓励修改后重投（Major Revision）。**

### 修改优先级

**必须修改（Critical → Major）：**
1. 对所有主要数据集实施正式的多重检验校正策略（建议使用 BH-FDR）。特别地，在全基因组范围内进行 31,764 次比较的脑区分析必须进行多重检验校正才能发表。
2. 修正 Bootstrap P 值的计算公式，考虑零分布不对称性。提供备选方案：使用 ω_obs 在零分布中的分位数，或使用重抽样比例的 2×min(比例)。
3. 解释 4,851/31,764 次成对比较样本中的非独立性问题（共享群体结构），并讨论对标准误/显著性检验的影响。

**建议修改（Major）：**
4. 将 Bootstrap 重抽样次数从 B = 500 增加至 B = 2,000–5,000，或提供正当的理由（至少 B = 1,000）。
5. 报告所有 Spearman ρ 值的 Bootstrap 95% 置信区间。
6. 讨论 ω 作为比值的统计特性（k_n → 0 时的行为，使用 delta 方法或 Fieller 定理的 CI）。
7. 明确主分析的实际 B 取值（稿件中 B = 500 vs. 投稿信中提及但未明确验证的其它数值）。

**可选修改（Minor）：**
8. 统一 JS 散度中对数底数的说明。
9. 在对数坐标轴上展示 ω 分布，以可视化偏态并减少视觉影响。
10. 对极小分组的 JS 散度引入方差稳定化或加权。
11. 将 "Cohen's d" 重命名为 "标准化排列效应量"。
12. 量化残差模型下基于百分位数的阈值与基于排列的阈值之间的一致性。

### 对编辑的说明

稿件在概念设计（将 Ka/Ks 启发式地应用于转录组学）和方法透明度方面具有优势。然而，在发表于 NAR 之前，**多重检验校正缺失**和**成对比较数量膨胀**是必须解决的统计学硬伤——这些是计算生物学中公认的标准做法，期刊审稿人将会将其标记出来。统计框架如果加上恰当的多重检验校正（BH-FDR）、正确的 P 值推导以及对方差结构的更充分讨论，会更加严谨。由于一篇方法学论文的可信度取决于其统计基础，当前版本在未进行实质性修改的情况下，不符合 NAR 所需的标准。上述技术问题是可解决的，强烈建议修改后重新提交。
