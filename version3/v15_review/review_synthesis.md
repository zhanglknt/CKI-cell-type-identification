## 2. 跨专家共识 Critical 问题（≥2位专家独立发现）

### CC1. JS散度对数底矛盾（4/4专家发现）
- **正文+补充材料**：base-2 logarithm，range [0, 1]
- **复现指南**：natural log (ln)，range [0, ln2≈0.693]
- **根因**：v14→v15修复仅更新了正文和补充材料的生成脚本，**复现指南未同步更新**
- **影响**：所有 k_n、k_f 绝对值和 ω 量级的解释
- **修复**：统一为 base-2，修正复现指南

### CC2. 归一化方法矛盾（3/4专家发现）
- **正文+补充材料**：softmax normalization
- **复现指南**：auto 模式（mouse/human/brain 用 sum-normalization，仅 TCGA 用 softmax）
- **根因**：同 CC1，复现指南未同步
- **影响**：sum-norm 与 softmax 在数学上有本质区别，跨数据集 ω 可比性存疑
- **修复**：正文修正为实际使用的 auto 模式，或统一代码实现

### CC3. Bootstrap P值公式矛盾（3/4专家发现）
- **正文**：P = 2×min(count(ω_null≥ω_obs)+1, count(ω_null≤ω_obs)+1)/(B+1)（双侧，检验 ω 值）
- **复现指南**：p = count(|ω_null-1|≥|ω_obs-1|)+1/(B+1)（单侧，检验偏离1）
- **影响**：两个公式的统计检验力完全不同
- **修复**：统一公式（建议使用复现指南版本，检验 |ω-1| 更符合中性假设）

### CC4. 大规模多重比较无FDR校正（3/4专家发现）
- 脑图谱 31,764 对 + 人类 4,851 对 + TCGA ~20,000 对，均无 BH-FDR
- 补充材料明文承认："NOT systematically applied"
- **统计学专家判断**：临界状态——若主要结论不依赖个体P值并标注为探索性，可降级为 Major；否则因 Bootstrap 分辨率限制（B=1000时最小P≈0.002，Bonferroni阈值≈1.57×10⁻⁶）升级为 Critical
- **修复**：增加 B 至 ≥100,000 或采用分析近似；至少对主要分析做 BH-FDR

### CC5. Bootstrap仅用于小鼠试点（2/4专家发现）
- **正文声称**：所有主要分析使用 bootstrap (B=1000)
- **复现指南揭示**：仅小鼠试点（15对，B=500）使用了 bootstrap
- 人类/TCGA/脑图谱均**无统计推断**
- **影响**：正文中大量 P 值和显著性声明来源不明或不存在
- **修复**：正文如实说明哪些分析使用了 bootstrap，未使用的标注为描述性

### CC6. 软件版本三重矛盾（2/4专家发现）
- **正文**：Python 3.12 + CKI v0.3.2
- **复现指南**：Python 3.13.12 + CKI v0.3.1
- **投稿信**：CKI v0.3.2
- **修复**：统一为实际版本（CKI v0.3.1, Python 3.13.12）

### CC7. 校准实验统计框架错误（2/4专家发现）
- n=6 校准实验使用标准假设检验（P>0.05→"无差异"），犯了 "absence of evidence is not evidence of absence" 错误
- 应使用 TOST 等效性检验
- ω=1.54 偏离理论值 1.0 达 54%，系统偏差需调查
- **修复**：使用 TOST 检验，扩大校准样本至 ≥100

### CC8. Cover Letter 缺推荐审稿人（1/4专家发现，但为 NAR 强制要求）
- NAR 要求 4-6 位推荐审稿人（附机构邮箱）
- 当前 Cover Letter 无任何推荐审稿人
- **修复**：添加 6 位推荐审稿人

## 3. 独立 Critical 问题（单专家发现）

### IC1. k_f 选择偏倚（循环论证）（方法学）
- k_f 使用 pairwise top-200 DE genes → 先选差异最大基因再算差异 = 循环论证
- ω 几乎必然 >1（k_f 被人为放大）
- **修复**：零模拟验证 + 比较 global HVG vs pairwise DE 模式

### IC2. 置信区间概念错误（统计学）
- 将置换零分布的 2.5th/97.5th 百分位数误认为 ω 的 95% CI
- 实际是检验临界值，不是参数置信区间
- **修复**：改用非参数 Bootstrap（有放回重采样细胞）计算 CI

### IC3. 人类数据对数矛盾（数据）
- 正文：4,851 对
- 复现指南运行时表：5,151 对
- **修复**：核实实际对数并统一

### IC4. k_n/k_f 术语三文档不一致（写作）
- 正文：baseline divergence rate / functional divergence rate
- 投稿信：neutral offset rate / functional conversion rate
- 补充材料：混用
- **修复**：统一术语

## 5. 根因分析

### 核心发现：复现指南未同步更新

v14→v15 修复仅作用于**正文和补充材料的生成脚本**（generate_manuscript_nar.py 和 68_gen_supplementary_en.py），但**复现指南（CKI_NAR_Reproducibility_Guide.docx）未同步更新**。

这导致了 CC1（对数底）、CC2（归一化）、CC3（P值公式）、CC6（软件版本）、IC3（数据对数）等 5 个 Critical 问题的出现——这些问题在正文/补充材料中已修复，但在复现指南中仍保留旧值。

**修复路径**：
1. 找到复现指南的生成脚本（可能是手动编写或旧脚本生成）
2. 逐项修正复现指南中的矛盾内容
3. 或重新生成复现指南

- 优势：scope最佳匹配，审稿人更懂单细胞方法
- 风险：统计要求同样严格
- 前提：修复全部Critical + FDR校正 + 校准实验

**方案C（快速发表）**：Briefings in Bioinformatics
- 优势：接收概率最高，理论要求宽松
- 劣势：IF较低
- 前提：修复全部Critical即可

## 9. 总结

CKI v15 在概念创新性（6.5/10）和写作质量（7/10）方面表现尚可，但在**文档一致性**（复现指南未同步更新导致5个Critical矛盾）、**统计严谨性**（FDR缺失、校准不足、CI概念错误）和**方法学理论深度**（k_f选择偏倚、ω=1无推导、Ka/Ks类比不严格）方面存在显著不足。

**核心问题可分类为两类**：
1. **机械性矛盾**（P0-1~P0-8, P0-13）：复现指南未同步 + Cover Letter不完整 → 8-10小时可修复
2. **学术性不足**（P0-9~P0-12, P1-1~P1-9）：需要补充分析、模拟和理论推导 → 3-5天

**建议修复路径**：
1. 先修复全部机械性矛盾（1天）→ 生成 v16
2. 再补充学术性内容（3-5天）→ 生成 v17
3. v17 投稿 NAR 或 Genome Biology
