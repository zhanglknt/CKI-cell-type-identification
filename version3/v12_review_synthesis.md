## 二、核心判断

CKI算法在**概念创新性**上具有突出优势——将Ka/Ks的"中性基线归一化"逻辑引入转录组比较领域是一个优雅的跨学科构思，填补了现有距离度量无法区分"功能性差异"与"背景噪音"的空白。验证规模宏大（4个数据集、百万级细胞），OPC阴性对照设计精妙，局限性讨论坦诚全面。

然而，v12稿件存在一个**系统性缺陷**：v11→v12的修复仅作用于正文DOCX，未同步至补充材料DOCX，导致引入了多处新的正文-补充材料矛盾。这些矛盾不是表述差异，而是直接影响计算结果的参数矛盾（归一化方法、对数底、样本数、迭代次数）。一位试图复现该工作的研究者将无法确定应使用哪套参数。

此外，统计严谨性存在根本性缺陷：31,764次比较未做任何多重检验校正，bootstrap检验统计量与经验零假设中心不一致，校准实验仅n=6无法支撑核心假设。

**结论**：概念优秀，执行不足。需要一轮系统性大修，重点解决正文-补充材料一致性、统计严谨性、方法学理论推导三个层面的问题。

## 三、跨维度共识问题（多位专家独立发现的Critical Issues）

以下6个问题被2-4位专家独立标注为Critical，是阻塞投稿的最高优先级修复项：

### 共识C1：JS散度对数底正文-补充矛盾（4/4专家标注）

- **正文 P021**: "JS divergence uses the **natural logarithm**"
- **补充材料 Note 1.1**: "D(p||q) = Σ p_i **log2**(p_i/q_i)... bounded in [0, 1]"
- **影响**: 对数底决定JS值域（base-2: [0,1] vs natural: [0, ln2≈0.693]），影响k_n绝对值解释和阈值含义
- **根因**: v11→v12声称已修复此P0问题，但修复仅在正文完成，补充材料未同步
- **修复**: 确认代码实际对数底→统一正文和补充材料→修正值域声明

### 共识C2：归一化方法正文-补充矛盾（3/4专家标注）

- **正文 Methods P021**: "sum-normalization for single-cell, softmax only for TCGA"
- **正文 Results P042**: "apply **softmax** normalization"（描述单细胞数据）
- **补充材料 Note 1.1/1.2 + Algorithm 1**: 全部使用 **softmax**
- **影响**: 归一化方法直接影响JS divergence值，进而影响所有k_n/k_f/ω计算
- **修复**: 确认代码实际使用的方法→统一全文→区分数据预处理（normalize_total+log1p）和CKI计算归一化（softmax/sum-norm）两个层次

### 共识C3：TCGA样本数三重矛盾（3/4专家标注）

- **正文 P027/P056**: LUAD 495+76, LUSC 567+58, LIHC 365+57, KIRC 755+82, BRCA 1032+109 = **3,596**
- **补充材料 Note 4.3**: LUAD 515+59, LUSC 501+51, LIHC 371+50, KIRC 533+72, BRCA 1093+113 = **3,358**（但声称总计 **10,535**）
- **影响**: 三个不同数字出现在稿件中，10,535是明显算术错误（分项之和仅3,358）
- **修复**: 核实实际样本数→统一正文和补充材料→修正10,535错误

### 共识C4：TPM vs FPKM矛盾（3/4专家标注）

- **正文 P027**: "TPM values, log2(x+1) transformed"
- **补充材料 Note 1.6 & 4.3**: "FPKM values from GDC"
- **影响**: TPM和FPKM是不同归一化方法，产生不同表达值，直接影响所有TCGA ω计算
- **修复**: 确认GDC数据实际使用的归一化方式→统一全文

### 共识C5：Bootstrap B值矛盾（4/4专家标注）

- **正文 P023/P038/P044**: B=500（P023还含冗余重复："B = 500 for mouse calibration and exploratory analyses; B = 500 for mouse calibration"）
- **补充材料 Note 3.1/3.2 + Algorithm 1**: B=1,000（default）
- **影响**: 不同B值产生不同P值和置信区间；B=500时最小P≈0.002，无法支撑P<0.001声明
- **修复**: 统一B值→建议所有主要分析使用B≥1,000→修正P023冗余

### 共识C6：多重检验校正全面缺失（3/4专家标注）

- 脑图谱: 31,764次比较，0次FDR校正
- Tabula Sapiens: 4,851次比较，0次FDR校正
- TCGA: 多临床变量检验，0次校正
- **影响**: 31,764次比较在P<0.05下期望~1,588个假阳性；30个Strong candidate（0.09%）的显著性无法评估
- **v11→v12回归**: v11有虚假FDR声明→v12移除虚假声明但走向另一极端（完全不校正）
- **修复**: 对所有大规模比较应用BH-FDR→报告q值→对30个Strong candidate报告排列检验FDR

## 八、审稿团队共识声明

1. 概念创新性突出（4/4专家肯定）

4. 局限性讨论坦诚全面（3/4专家肯定）

**建议**：在修复全部P0问题后，执行一次完整的"正文-补充材料一致性校验"（逐参数交叉核对），确保所有方法学参数在两个文档中完全一致。这是将投稿准备度从45%提升至70%+的关键步骤。
