2. CKI Algorithm Definition
CKI decomposes transcriptomic divergence into two components:
omega = k_f / k_n
where:
k_n  = JS(p_HK_A || p_HK_B)       ... baseline divergence rate
k_f  = JS(p_ID_A || p_ID_B)       ... functional divergence rate
and JS(P || Q) is the Jensen-Shannon divergence (base-2 logarithm, range [0, 1]):
M        = 0.5 * (P + Q)
JS(P||Q) = 0.5 * KL(P||M) + 0.5 * KL(Q||M)
where KL(P||M) = sum_i [ P_i * log2(P_i / M_i) ]  for P_i > 0
Both k_n and k_f use the same computational pipeline: (1) subset the pseudobulk expression vector to the relevant gene indices; (2) apply softmax normalization to convert expression values into a probability distribution:  p_i = exp(x_i) / sum_j exp(x_j); (3) compute JS divergence between the two resulting distributions. This internal consistency (same metric, same normalization, same underlying expression space) ensures omega is self-calibrated.
3. Gene Set Selection
3.1 Housekeeping Genes (for k_n)
In all reported analyses, housekeeping (HK) genes were loaded from
the HRT Atlas v1.0 reference (Hounkpe et al., NAR 2021) via the file
data/housekeeping/Human_Mouse_Common.csv (1,130 human-mouse conserved
HK genes; identical to cki/data/hrt_atlas.csv).

For each dataset, HK genes were loaded as follows:
  Tabula Muris (mouse):   HRT Atlas mouse genes (column 0),
  Tabula Sapiens (human): HRT Atlas human genes (column 1),
  TCGA (human):           HRT Atlas human genes (column 1),
  Siletti Brain (human):  HRT Atlas human genes (column 1).

The CKI package also supports data-driven auto-detection via
detect_housekeeping_genes() (detection rate > 0.9, CV < 30th
percentile, "combined" method; use_reference=False by default),
but this was NOT used in the reported analyses.
3.2 Identity Genes (for k_f)
Identity (functional) genes are defined as:
Default (CKI): top-2,000 highly variable genes (HVGs; Scanpy seurat flavor), with HK genes explicitly excluded to maintain k_n/k_f independence (adapted to min(2000, 0.8 * n_total_genes)).
Hybrid mode: global k_n computed once with shared HK gene set; per-pair k_f uses the top-200 differentially expressed genes (ranked by |mean_diff| between the two groups), excluding HK genes.
The default mode (global HVG 2,000) is used for the Tabula Muris full pairwise matrix (03_full_matrix.py, 703 pairs, Fig. 2 heatmap). The hybrid mode (per-pair top-200 DE) is used for Tabula Muris pilot analyses (calibration controls + validation, 02b_pilot_v2.py), Tabula Sapiens (human), TCGA, and brain atlas analyses to give each cell-type pair the most informative identity genes while keeping all pairs on a common k_n scale. The parameter sweep (Supplementary Figure 1) confirmed that the identity-only configuration (w1 = 1.0, w2 = 0.0) achieves the best cell-type discrimination without external pathway databases.
4. Data Sources & Preprocessing
4.1 Tabula Muris (Mouse) — Result 2 (Fig. 2)
Dataset:    Tabula Muris FACS (Schaum et al., Nature 2018)
Source:     https://github.com/czbiohub-sf/tabula-muris
Technology: SmartSeq2
Data used:  15,057 cells, 22,308 genes, 6 organs (Liver, Kidney, Spleen, Lung, Heart, Marrow)
Processing:
  1. Load per-tissue count matrices (FACS/tissue-counts.csv).
  2. Intersect to common gene set across all tissues.
  3. Normalize: sc.pp.normalize_total(target_sum=1e4), then log1p.
  4. Pseudobulk: mean expression per cell-type annotation.
  5. Filter: cell types with < 10 cells excluded.
  6. Compute global k_n on all cell-type pseudobulks (shared HK set).
  7. Compute per-pair k_f with global HVG set (2,000 genes, HK excluded).
  8. Bootstrap: n = 1,000 permutations, one-sided test (P = (count(ω_null ≥ ω_obs) + 1)/(B + 1)).
Controls: Six random-split comparisons (same cell population divided into two halves) tested baseline behavior (empirical baseline omega ~ 6.67).
Total pairs: 703 cell-type pairs across 6 organs.
4.2 Tabula Sapiens (Human) — Result 3 (Fig. 3)
Dataset:    Tabula Sapiens (Jones et al., Science 2022)
Source:     https://github.com/czbiohub-sf/tabula-sapiens
Technology: 10x Genomics (3′ and 5′ assays)
Data used:  108,136 cells (6 h5ad files total), 102 cell-type entries, 6 organs (Liver, Kidney, Heart, Bone Marrow, Spleen, Lung)
Processing:
  1. Load per-organ h5ad files (TS_{Organ}.h5ad; e.g., TS_Liver.h5ad, TS_Kidney.h5ad, etc.).
  2. Intersect to common gene set across all 6 organs.
  3. Within each organ: filter cells with < 500 genes, then normalize: sc.pp.normalize_total(target_sum=1e4), log1p.
  4. Pseudobulk: mean expression per cell_type_ontology_term_id.
  5. Global k_n: JS divergence on full pseudobulk matrix with shared HK set.
  6. Per-pair k_f: top-200 DE genes (ranked by absolute mean difference), HK genes excluded.
  7. Full pairwise omega computed for all 5,151 cell-type pairs.
Method comparison: Spearman rank correlation computed between CKI omega and four standard metrics on all 5,151 cell-type pairs:raw JS divergence (all genes), Spearman distance (1 - Spearman r), cosine distance (1 - cosine similarity), marker Jaccard distance (1 - intersection/union of top-200 marker genes per cell type). Classification AUC from cell-type pair classification task (same-type vs. different-type) computed with sklearn.metrics.roc_auc_score.
4.3 TCGA (Human Cancer) — Result 4 (Fig. 4)
Dataset:    TCGA Pan-Cancer (Hutter & Zenklusen, Cell 2018; Liu et al., Cell 2018)
Source:     UCSC Xena (https://xenabrowser.net/), file: tcga_RSEM_gene_tpm.gz
Data used:  3,596 samples (from 10,535 raw TCGA samples after filtering) across 5 cancer types: LUAD, LUSC, LIHC, KIRC, BRCA
Processing:
  1. Filter: gene-level mean expression > 1 TPM within each cancer type (per-cancer independent filtering).
  2. log2(TPM + 1) transformation.
  3. Pseudobulk: mean expression per sample.
  4. Sample pairs drawn from: tumor-tumor (TT), normal-normal (NN), tumor-normal (TN). Maximum 2,000 random TT and TN pairs each.
  5. Global k_n computed once per cancer type using shared HK genes.
  6. Per-pair k_f with top-200 DE genes (ranked by |mean_diff|).
  7. NN/TT ratio computed as mean(omega_NN) / mean(omega_TT) per cancer type.
Clinical stratification:
  LIHC Edmondson grade: G1 (n=39), G2 (n=133), G3 (n=105), G4 (n=11). Jonckheere-Terpstra trend test.
  BRCA PAM50 subtype: Basal-like (n=97), HER2 (n=55), LumA (n=224), LumB (n=123), Normal-like (n=7). Kruskal-Wallis test.
  LUAD mutation: EGFR (n=61), KRAS (n=120), WT (n=311). Kruskal-Wallis test.
4.4 Siletti Brain Atlas (Human) — Results 5 & 6 (Fig. 5 & 6)
Dataset:    Siletti et al. (Science 2023)
Source:     https://github.com/linnarsson-lab/snRNA_brain_atlas
Technology: snRNA-seq (10x Genomics)
Data used:  888,263 non-neuronal nuclei, 108 brain regions, 10 cell classes
Processing:
  1. Load Nonneurons.h5ad in backed mode (backed='r') for memory efficiency.
  2. Map gene symbols from var["Gene"]; match HK genes from HRT Atlas (1,130 human genes) to gene symbol column.
  3. Group by (cell_type, brain_region). Filter groups with < 20 nuclei.
  4. Build pseudobulk vectors: raw count means per (ct, region) group, then normalize_total (target_sum=1e4) and log1p at the pseudobulk level.
  5. Compute omega for all same-cell-type cross-region pairs (31,764 pairs total).
  6. Organize omega values per cell type and per region pair.
Cross-organ conservation (Fig. 5): Subset of 59 same-cell-type cross-organ pairs from Tabula Sapiens data. Ranked by mean omega per cell type.
Migration detection model (multiplicative):
For each (cell_type, region_pair) combination:
expected_omega = mu_ct * mu_pair / mu_grand
where mu_ct = cell type’s global mean omega, mu_pair = region pair’s mean omega, mu_grand = global mean (8.01).
residual = observed_omega / expected_omega
Confidence tiers:
  Strong:   residual < 0.3, omega < 15, lowest omega in region pair.
  Moderate: residual < 0.5, omega < 25.
  Weak:     residual < 0.75, omega < 35.
5. Statistical Testing
5.1 Bootstrap Permutation Test
For each cell-type pair comparison, the null hypothesis H0: no functional divergence beyond baseline is tested via permutation:
  1. Pool all cells from groups A and B.
  2. For each of B iterations (B = 1,000 for all datasets):
     a. Randomly permute cell labels.
     b. Split into two groups of original sizes.
     c. Recompute pseudobulks and omega.
  3. Null distribution = {omega_perm[1], ..., omega_perm[B]}.
  4. P-value (one-sided permutation test):
p = (count(omega_null >= omega_obs) + 1) / (B + 1)
  5. Effect size: Cohen’s d = (omega_obs - mean_null) / std_null.
  6. Test critical values at alpha=0.05: [percentile(null, 2.5), percentile(null, 97.5)]. Note: these are permutation-based test critical values for rejecting H0, NOT confidence intervals for omega itself.
5.2 Notes on Execution
Benjamini-Hochberg FDR correction is applied to the bootstrap P-values within each dataset. The q-value column in the bootstrap output CSV files (tcga_bootstrap_results.csv, human_bootstrap_results.csv, brain_bootstrap_results.csv) provides the FDR-adjusted significance. The BH procedure is implemented in cki/bootstrap.py:benjamini_hochberg().
5.3 Phase B Statistical Upgrades
Three additional statistical analyses were performed to address reviewer concerns (Phase B):

  a. Adaptive permutation analysis (C-S1):
     Script: notebooks/09_phaseB_statistical_upgrades.py
     Verified that B=1,000 is sufficient because bootstrap tests are at the cell-type level (10 brain, 17 human, 15 mouse), not the pair level. The minimum resolvable P-value (1/1001 = 9.99e-4) is well below the BH threshold for the top-ranked test in each dataset.

  b. Bootstrap confidence intervals (C-S2):
     Script: notebooks/09_phaseB_statistical_upgrades.py
     95% CIs computed by pair-level resampling (B=10,000) for all key omega estimates. Output: results/phaseB_bootstrap_cis.csv.

  c. Permutation null for residual model (C-S3):
     Script: notebooks/09b_phaseB_residual_pervisign.py (empirical) + 09c_phaseB_residual_evt.py (EVT)
     For each of 31,764 brain region pairs, cell type labels were shuffled B=10,000 times. Per-signal empirical P-values: P = (count(null_residual <= observed) + 1)/(B+1). 11,541 signals reached the empirical P-value floor (P=9.99e-5). To resolve saturation, extreme value theory (GPD tail extrapolation, K=500 smallest nulls) was applied, yielding sub-floor P-values spanning 1e-10 to 9.99e-5 (11,541/11,541 GPD fits successful). BH-FDR applied across all 31,764 pairs using combined EVT-empirical P-values. Result: 11,556/31,764 pairs FDR<0.05. Within the 30 Strong-tier signals: 16/30 significant (all 6 astrocyte + 10 oligodendrocyte FDR<0.05), 14/30 not significant (P>=0.76, q=1.0). Output: results/phaseB_residual_evt.csv.

  d. Omega distribution characterization (C-S5):
     Script: notebooks/09_phaseB_statistical_upgrades.py
     Computed skewness, kurtosis, and normality tests (Shapiro-Wilk, D'Agostino-Pearson) for all datasets. All omega distributions are right-skewed and non-normal. Cohen's d reported as descriptive measure. Output: results/phaseB_omega_distribution.json.
5.4 Phase C Methodological Reinforcement
Three methodological analyses were performed to address reviewer concerns (Phase C):

  a. Calibrated omega normalization (C-M1):
     Script: notebooks/09c_phaseC_methodological.py
     Calibrated omega: omega_cal = omega / 6.67 (empirical baseline from mouse split-half, n=6). Rescales all values so equivalent populations yield omega_cal ~ 1.0. Brain global mean: 8.01 -> 1.20; astrocytes: 14.36 -> 2.15; Bergmann glia: 2.37 -> 0.36. Function: cki.calibrate_omega(). Output: results/phaseC_calibration.json, results/phaseC_calibrated_omega_brain.csv.

  b. JS divergence dimensionality invariance (C-M2):
     Script: notebooks/09c_phaseC_methodological.py
     Simulation of 2,000 random Dirichlet distribution pairs across dimensions 50-5,000. Mean JS divergence is effectively constant (0.155-0.159; ratio=1.001 between d=1,130 and d=2,000), confirming that k_f inflation arises from HVG selection bias, not dimensional mismatch. Output: results/phaseC_dimensionality.json, results/phaseC_dimensionality_simulation.csv.

  c. Pair-specific k_n variability (C-M3):
     Script: notebooks/09c_phaseC_methodological.py
     Per-pair k_n across 31,764 brain comparisons: CV=97.35% (mean=0.0141, median=0.0086). Spearman rho between per-pair omega and global-kn omega = -0.027 (P=9.96e-7), confirming pair-specific k_n yields substantially different rankings. Justifies per-pair k_n approach for brain analysis. Output: results/phaseC_kn_variability.json, results/phaseC_kn_stats.csv, results/phaseC_omega_pair_vs_global.csv.
