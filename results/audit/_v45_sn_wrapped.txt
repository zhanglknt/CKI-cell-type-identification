0021| Supplementary Note 1: CKI Mathematical Derivation
0022| 1.1 Jensen-Shannon Divergence
0023| The Jensen-Shannon (JS) divergence is a symmetrized and smoothed version of the Kullback-Leibler divergence. For two probability vectors p and q: JS(p, q) = 1/2 D(p||m) + 1/2 D(q||
0023| m), where m = 1/2(p+q), and D(p||q) = 危 p_i log2(p_i/q_i). When using the base-2 logarithm, the JS divergence is bounded in [0, 1]. This bound is important for interpreting 蠅: when
0023|  both k_n and k_f approach 1, 蠅 = k_f/k_n may still vary. A small floor value (1e-4) on k_n is applied only in the TCGA bulk RNA-seq analysis (where pseudobulk averaging across mil
0023| lions of cells compresses HK gene variance and drives aggregate k_n toward zero) to prevent inflated 蠅 from near-zero denominators; all single-cell analyses (mouse, Tabula Sapiens,
0023|  brain atlas) apply no floor (kn_floor = 0, positivity guard only; minimum observed per-pair k_n: 1.1e-4, mouse; 6.3e-4, human; 9.2e-5, brain; under the reported brain pipeline, on
0023| ly 1 of 31,764 pairs had k_n below 1e-4, and these values entered 蠅 uncapped). Before computing JS divergence, both pseudobulk vectors are mapped to probability distributions by a 
0023| softmax over the log-transformed values (cki.utils.ensure_probability_distribution, mode = "softmax"). For single-cell data (natural-log log1p of library-size-normalized counts) th
0023| is mapping is exactly linear in the normalized counts: softmax(log1p(x)) yields p_i = (x_i + 1)/危(x_j + 1), equivalent to a +1 pseudo-count followed by L1 normalization. For TCGA b
0023| ulk RNA-seq (log2(TPM + 1) values) the same softmax is mathematically equivalent to a power transformation, p_i 鈭?(TPM + 1)^(1/ln 2) = (TPM + 1)^1.4427, which earlier versions of t
0023| his document did not disclose. A full re-analysis of the TCGA pipeline under a strictly linear mapping, p_i = (TPM + 1)/危(TPM + 1), leaves every qualitative conclusion unchanged (r
0023| obustness table in Note 1.7).
0024| 1.2 Baseline Divergence Rate k_n
0025| Housekeeping (HK) genes are defined as genes that maintain stable expression across cell types and conditions. Let H = {g1, ..., gM} be the set of HK gene indices. Given pseudobulk
0025|  vectors 渭_A and 渭_B (length G, total number of genes), the baseline divergence rate is: k_n = JS(norm(渭_A[H]), norm(渭_B[H])), where norm() denotes +1 pseudo-count addition followe
0025| d by L1 normalization. Rationale: HK genes should not exhibit systematic differences between biologically identical cell populations. The JS divergence observed on HK genes therefo
0025| re reflects baseline noise: technical variation, stochastic transcriptional bursting, and individual-level physiological differences. k_n thus provides an internal baseline, heuris
0025| tically analogous to Ks (synonymous substitution rate) in molecular evolution. HK gene set selection: HK genes were loaded from the HRT Atlas v1.0 reference (1,130 human-mouse cons
0025| erved HK genes) [13]. For mouse datasets, the mouse ortholog column is used; for human datasets (Tabula Sapiens, TCGA, brain atlas), the human gene column is used. The CKI package 
0025| also supports data-driven auto-detection via detect_housekeeping_genes() (combined criterion: detection rate > 0.9 and CV < 30th percentile, use_reference = False), but all reporte
0025| d analyses use the pre-specified HRT Atlas reference. Sensitivity analysis indicates that CKI results are robust to HK set selection: using the top 10% lowest-variance genes as an 
0025| alternative constrained set yields 蠅 correlations of r > 0.95.
0026| 1.3 Functional Divergence Rate k_f
0027| Identity genes I are defined as genes that capture cell-type-specific functional programs. In the default configuration (w1 = 1.0, w2 = 0.0), I consists of the top-N highly variabl
0027| e genes (HVG), excluding HK genes. The functional divergence rate is: k_f = JS(norm(渭_A[I]), norm(渭_B[I])). Extended configurations can incorporate additional gene sets: (1) regulo
0027| n activity genes 鈥?genes enriched for cell-type-specific transcription factor motifs; (2) pathway enrichment genes 鈥?genes from MSigDB pathways differentially active between the tw
0027| o groups; (3) macro-gene embeddings 鈥?gene-level embeddings from protein language models (e.g., ESM-2). These extensions use a weighted formulation: k_f = w1*JS(HVG) + w2*JS(pathwa
0027| y) + w3*JS(macro). Parameter sweep (Phase 3.2) showed that the pure identity gene configuration (w1=1.0, w2=w3=0.0) achieved optimal cell type discrimination (AUC = 0.786, n = 703 
0027| mouse cell-type pairs); this was therefore adopted as the default scheme.
0028| 1.4 Omega Ratio and Its Interpretation
0029| 蠅 = k_f/k_n. Interpretation is anchored in the empirical 蠅 distribution within each dataset rather than in fixed ratio cut-offs: values close to the equivalent-population calibrati
0029| on baseline are consistent with baseline expectation, with no evidence of functional reprogramming; values far above the baseline indicate functional divergence exceeding baseline

0030| 1.5 Permutation Test
0031| Statistical inference is performed by generating a null distribution of 蠅 under the null hypothesis that the group labels are exchangeable between the two cell populations. Procedu
0031| re: (1) Annotate all cells in the pooled dataset with their original group labels (A or B); (2) Randomly permute group labels B times (B=1,000): cell labels for mouse and human, sa
0031| mple (tumor/normal) labels for TCGA; for the brain atlas the authoritative null is the library-to-region block-shuffle permutation rather than label permutation; pseudobulk vectors
0031|  and omega_null are recomputed each time, with the top-N identity genes re-selected on the permuted pseudobulks in the mouse, human, and brain pipelines, while the TCGA per-cancer 
0031| permutation test holds a fixed HVG panel across permutations (anti-conservative relative to re-selection); (3) Empirical P-value (one-sided): P = (count(蠅_null 鈮?蠅_obs) + 1)/(B + 1
0031| ), with the +1 term avoiding P = 0; (4) Effect size: SES = (omega_obs - mean(omega_null))/sd(omega_null). Benjamini-Hochberg FDR correction is applied within each dataset to contro
0031| l the false discovery rate. Because the test is one-sided, rejection at a given alpha is decided directly by the empirical P-value (P < alpha); no separate two-sided critical value
0031| s are derived from the null distribution, and the null quantiles are not confidence intervals for 蠅 itself. Permutation testing was performed for all four datasets: label permutati
0031| on for the mouse pilot (15 cell-type pairs), human Tabula Sapiens, and TCGA (B=1,000 each), and the block-shuffle null for the brain atlas (B=1,000). For the larger-scale analyses,
0031|  results are supplemented with non-parametric statistical tests (Spearman correlation, Mann-Whitney U, Kruskal-Wallis, Jonckheere-Terpstra) and descriptive statistics.
0032| 1.6 Pseudobulk Construction
0033| Raw count matrices X (cells x genes) are preprocessed as follows: (1) Library size normalization: X_norm = 10,000 * (X/colSums(X)); (2) log1p transformation: X_log = log1p(X_norm),
0033|  stabilizing variance and reducing the influence of high-expression outliers; (3) Pseudobulk: mu = column-wise mean of X_log for all cells with the same cell type annotation, with 
0033| a minimum of 10 cells per group. For TCGA bulk RNA-seq data, TPM normalization is used instead: TPM values from UCSC Xena, followed by log2(TPM + 1) transformation. No pseudobulk s
0033| tep is needed as each sample is already a bulk expression profile.

0039| Algorithm 1: CKI Core Computation
0040| Input: Two cell populations A and B (expression matrices), HK gene set H, identity gene set I (default top-N HVG excluding H). Output: 蠅, P-value, SES, null distribution.
0041|  1. X_A, X_B <- library-normalize and log1p-transform A and B
0042|  2. mu_A <- mean(X_A, axis=0); mu_B <- mean(X_B, axis=0)  // pseudobulk
0043|  3. mu_A_H <- mu_A[H]; mu_B_H <- mu_B[H]
0044|  4. k_n <- JS_divergence(norm(mu_A_H), norm(mu_B_H))  // norm: softmax over log1p counts, i.e., p_i = exp(log1p(c_i)) / sum_j exp(log1p(c_j)) = (c_i+1) / sum_j (c_j+1)
0045|  5. mu_A_I <- mu_A[I]; mu_B_I <- mu_B[I]
0046|  6. k_f <- JS_divergence(norm(mu_A_I), norm(mu_B_I))
0047|  7. if (bulk RNA-seq analysis) and k_n < 1e-4: k_n <- 1e-4  // TCGA-only floor; single-cell analyses apply no floor
0048|  8. omega <- k_f / k_n
0049|  9. // Permutation test
0050| 10. labels <- concatenate([A]*n_A, [B]*n_B)  // for bulk RNA-seq, one label per sample
0051| 11. for b = 1 to B (B = 1,000 for all datasets):
0052| 12.     labels_perm <- random_permutation(labels)
0053| 13.     mu_perm1 <- mean(pooled[labels_perm[:n_A]], axis=0); mu_perm2 <- mean(pooled[labels_perm[n_A:]], axis=0)
0054| 14.     I_b <- top-N identity genes selected on (mu_perm1, mu_perm2)  // re-selected at every permutation
0055| 15.     omega_null[b] <- CKI_core(mu_perm1, mu_perm2, H, I_b)
0056| 16. // Inference (one-sided permutation test)
0057| 17. P <- (count(omega_null >= omega_obs) + 1) / (B + 1)
0058| 18. d <- (omega - mean(omega_null)) / sd(omega_null)

0059| and held fixed, while the k_f gene set is re-selected at every permutation (and for the observed value) as the top 200 non-HK genes by absolute pseudobulk difference, so the null i
0059| ncorporates the gene-selection step; this is the label-permutation procedure reported for the mouse pilot and Tabula Sapiens analyses. Passing explicit identity gene sets, or resel
0059| ect_identity = False, pins a fixed panel across permutations (legacy mode; anti-conservative relative to re-selection whenever the observed 蠅 uses per-pair selection). The TCGA per
0059| -cancer permutation test deliberately held a fixed identity panel across permutations (anti-conservative relative to re-selection; see 1.5 Permutation Test), and the brain analysis
0059|  uses a library-level block-shuffle null (cki.blocknull.block_shuffle_test) instead of label permutation.

0085| nt populations) arises from HVG selection bias (selecting genes with high cross-cell variance) rather than from dimensional mismatch between the HK and HVG gene sets. We note that 
0085| this simulation addresses dimensionality per se (random probability vectors of different lengths) but does not simulate the variance-based gene selection mechanism that generates t
0085| he 蠅 inflation. A more complete validation would test whether the inflation magnitude scales with the stringency of variance filtering rather than gene count. The calibrated 蠅 (ome
0085| ga_cal = 蠅 / 7.70) absorbs this bias into the empirical baseline, and the permutation null distribution - constructed using the same gene sets as the observed data - ensures intern

0088| 3.8 TCGA Exploratory Analysis Caveats
0089| The TCGA pan-cancer analysis (Results Section: Cancer analysis) is exploratory in nature due to several inherent limitations of bulk RNA-seq data. First, bulk RNA-seq confounds cel
0089| l-composition shifts (tumor purity, stromal infiltration, immune cell infiltration) with genuine transcriptional divergence; the observed NN/TT > 1.0 pattern may partly reflect sha
0089| red cell-composition changes across tumors rather than true transcriptional convergence. Second, peritumoral inflammation and desmoplastic reactions are shared across tumors and co
0089| uld contribute to apparent convergence. Third, systematic RNA quality differences between tumor and normal specimens may introduce technical bias. Fourth, the paired tumor-normal a
0089| nalysis (n = 2-5 per cancer type) lacks statistical power for formal hypothesis testing (minimum two-sided P approx 0.33 for n = 2); we therefore report paired comparisons as descr
0089| iptive statistics only. Fifth, PAM50 and Edmondson stratification includes small subgroups (Normal-like n = 7; Edmondson G4 n = 11) whose rankings are unreliable. Sixth, the PAM50 
0089| gradient (aggressive subtypes have lower 蠅) may be driven by proliferative fraction differences rather than shared transcriptional states. These caveats do not invalidate the descr
0089| iptive findings but preclude causal inference from bulk-level data alone.

0092| 3.10 One-Sided Permutation Test Justification
0093| All permutation P-values use a one-sided test: P = (count(omega_null 鈮?omega_obs) + 1)/(B + 1). The one-sided formulation is appropriate because our hypothesis is directional: we t
0093| est whether observed 蠅 exceeds the null expectation (equivalent populations), not whether it differs in either direction. A two-sided test would be appropriate if we were testing f
0093| or any departure from the null (either elevated or suppressed 蠅). However, the biological questions addressed here (functional divergence exceeding baseline, Strong region-associat
0093| ed candidates showing anomalously low 蠅) are inherently directional. One exception: the brain per-pair candidate screen uses the one-sided lower-tail formula P = (count(omega_null 
0093| 鈮?omega_obs) + 1)/(B + 1), because region-associated candidates are defined by anomalously low 蠅; the complementary upper-tail P-value is computed for every pair and both tails are
0093|  reported. In the released cki package (v0.4.8), the tested tail is selected by the tail parameter of bootstrap_test() and block_shuffle_test() (tail = "upper", "lower", or "two-si
0093| ded"); earlier releases used the parameter name "direction".
