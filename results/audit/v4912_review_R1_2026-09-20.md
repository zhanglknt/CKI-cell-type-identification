## 总评（3-5 句）

本版的估计器定义、推断机器与披露标准已达到可发表的方法学水准：permutation null 在每次置换中重选 identity 基因集从而内化循环选择、block-shuffle null 保留 10x 文库块结构并以 pseudo-region 负对照与 donor-stratified 变体验证校准、fixed-panel ablation 将循环性膨胀定量为"秩稳健、绝对值上界"、softmax 幂变换问题以线性归一化全量重算（XV3 口径）修复且全篇口径统一。作者对本方法的结构性盲区（anchor 上的功能性信号不可见、锚点漂移时比值被消灭、绝对 ω 跨数据集/跨方案不可转移）的陈述诚实到近乎自我拆解，且所有声明均能在我核对的三份文本中找到一致的支撑数字。遗留问题不再涉及概念或推断框架本身，而是若干局部统计口径（LUAD 驱动组检验的二元依赖、校准常数对离群群体的依赖）与参数敏感性缺口（top-200 的 N 无真实数据扫描），均可在小修内解决。

## 主要问题（编号列出，注明行文位置）

**N1. 校准常数 7.70 对离群对照群体（hepatocyte）的依赖性未做敏感性分析。**
SI Section 3.10 报告六个对照群体的 50 次重复均值：hepatocyte 12.44 ± 5.98，其余五群为 5.77–7.36。全局均值 7.70 被单一离群群体系统性拉高（去 hepatocyte 后约 6.8，差 ~13%），而该常数通过 ω_cal = ω/7.70 进入主稿所有换算表述（brain 全局 ≈5、astrocytes ≈11、Bergmann glia ≈1.8）。文本未报告 leave-one-population-out 敏感性或稳健（中位数）基线，也未讨论 hepatocyte 高基线是否反映肝脏代谢基因与 HRT Atlas 的交集问题。要求：补充 leave-one-out 基线表，并说明 Bergmann glia ω_cal ≈1.8/1.4 这类贴着 1 的结论是否跨基线稳定（该结论的 CI [0.99, 2.12] 已含 1，故方向不受威胁，但幅度表述需稳健化）。位置：主稿 Methods "Robustness and calibration analyses"；SI 3.10、Note 3。

**N2. LUAD 驱动基因分组的推断检验未处理 per-tumor 统计量的二元依赖（dyadic dependence），与全文其他处理形成双重标准。**
主稿 Results（"A pan-cancer map" 第 2 段，第 49 行）明确承认 per-tumor ω 是"所有参与 TT 对（含跨驱动组对）的均值，组均值来自非不相交对集"；同一稿件将 pair-level Mann-Whitney 因同样的二元依赖降级为 "descriptive only"（第 48、125 行），但 LUAD 的 Kruskal-Wallis（P = 7.8 × 10⁻⁷）、Dunn–Holm 各对比、以及 admixture/smoking 调整后的 P 值（Δω +16.8，P = 4.0 × 10⁻⁶；SI 3.13）仍按独立样本推断。虽然每肿瘤平均仅参与 4–11 对、依赖图稀疏、效应量级大，结论大概率稳健，但方法口径必须统一。要求：以 sample-level cluster/permutation 检验（或对 disjoint pair 子集）重算驱动组对比的 P 值，或将 KW/Dunn 同样标注为 descriptive 并只以 cluster-bootstrap CI 支撑。位置：主稿 Results 第 49 行；Methods "Per-sample divergence and group statistics (TCGA)"；SI 3.13；Fig. 4b–d。

**N3. 单细胞管线两种聚合顺序并存（softmax(log1p(mean counts)) vs softmax(mean(log1p))），且未声明包默认值与推荐。**
Methods "CKI computation"（第 92 行）正确披露了 brain 与 mouse/human 管线在 log1p 与平均的先后顺序上不同、二者数学上不是同一个量，并将其列为校准常数不可转移的部分原因。但：(i) 两种顺序无优劣论证、无统一计划；(ii) 复现指南与 Algorithm 1 的伪代码只描述了与 brain 顺序等价的一种；(iii) "internally calibrated" 的保证严格限于同管线内，而文本未对跨管线复用（用户最可能的误用方式）给出显式警告。要求：指定其一为包 v0.5.x 的唯一默认并在文档中标记另一顺序为 legacy，或在 Methods 中加一句显式的跨管线不可比警告。位置：主稿 Methods 第 92 行；SI 1.1、Algorithm 1；Reproducibility Guide Section 2。

**N4. hybrid 方案的核心参数 top-200 DE 基因数 N 在真实数据上没有任何敏感性分析；且该方案唯一一次形式化参数优化（w-sweep）使用的是跨类型 AUC 目标，与声明的 scope 不一致。**
(i) 检查全部敏感性分析：TS 上变的是 HVG 数（{2,000–20,000}，SI 4.4）、模拟里变的是 module 大小（m = 50/200/500，Note 1）、tier 阈值网格变的是 residual/ω 上限（Repro Guide 5.6e）——唯独 per-pair top-200 的 N 本身在真实数据上从未被扫描。鉴于 k_f 的选择底噪（median baseline k_f = 0.025）被本文自己证明是 ω 检验功效的结构性决定因素（主稿第 33–34 行），N 的敏感性直接关系到方法的可用域。要求：在 brain 或 TS 子集上补 N ∈ {100, 200, 500} 的秩相关与校准基线敏感性。(ii) Supplementary Fig. 1 / SI 1.3 承认默认配置由跨类型判别 AUC = 0.786 选出，而主稿 Discussion（第 82 行）声明 CKI 的 scope 是"同一细胞类型内状态变化、跨类型区分度低为设计使然"。SI 已加"gene-set configuration criterion only"的限定语，但参数选择目标在 scope 之外这一张力应至少在 Discussion 的 scope 段落正面回应。位置：主稿 Methods 第 19、82 行；SI 1.3、3.9、4.4；Supplementary Fig. 1。

**N5. Augur 对比的 primary variant 为 post-hoc 选择，且实现为非官方自报验证的移植。**
SI Note 14：multiclass macro-OvR 因 AUC 与 eligible-region 数相关（ρ = −0.744）被定为 confounded，binary OvR 被定为 primary——这是在看到两个结果之后的选择规则；n = 10 下所有相关（ω ρ = 0.442 P = 0.200；k_f ρ = 0.564 P = 0.090）均为 descriptive，文本已如实标注，但"complementary rather than redundant"的结论（主稿第 76 行）在这份证据下最多是"不矛盾"。另外 pyaugur 0.1.0 的 ρ = 1.0（对 R 参考实现）是移植作者自报，未经作者独立核验。要求：(i) 两个 variant 并列呈现而非主/副定级（sensitivity 标注保留即可，去掉"primary"字样或在 Methods 中声明选择规则的时间顺序）；(ii) 在至少一个公开基准上独立抽查 pyaugur 与 R Augur 排名的一致性。位置：主稿 Discussion 第 76 行；SI Note 14；Repro Guide 5.9d–e。

## 次要问题

**n1. Kang 0/30 的 CI 标注错误。** 主稿第 37 行 "0 of 30, Wilson 95% CI [0.000, 0.114]"：0/30 的 Wilson 上界约为 0.107，0.114 是 Clopper-Pearson 上界（1 − 0.025^(1/30) ≈ 0.116）；同段 11/30 的 [0.219, 0.545] 与 7/30 的 [0.118, 0.409] 经我复算确为 Wilson。请核对标签或数值。位置：主稿 Results 第 37 行；SI 3.12。

**n2. 最低细胞数阈值文本不一致。** SI 1.6 写 "minimum of 10 cells per group"，而主稿 Methods 第 91 行与 SI 4.1/4.2/Repro Guide 均为 ≥20 cells。SI 1.6 应为遗留文本，请更正。位置：SI 1.6 vs SI 4.1、主稿 Methods。

**n3. Statistical conventions 段的 bootstrap 次数陈述与正文不符。** 主稿第 127 行 "Bootstrap 95% confidence intervals use B = 10,000 resamples"，但文中实际使用的区间分别有 B = 200（composition）、1,000（TCGA 比值）、2,000（region-clustered）、5,000（joint/studentized）。建议改为"分层报告，B 见各方法段"。

**n4. 候选目录正文篇幅与其统计地位不匹配。** C2 框架已在开头给出全局裁决（39 观测 vs 148.3 期望、min q = 0.520、P(null ≥ 39) = 1.0），但随后仍以约两页正文逐类列举候选并附文献机制讨论。方法学上无新错误（tier–P 值的数学耦合已在 Note 13 申报），但建议将逐类目录压缩进 SI，正文保留裁决 + tier 统计 + 一段最显著示例，以免读者在统计地位与叙事篇幅之间产生错觉。位置：主稿 Results "Anomalously similar pairs" 全节。

**n5. TCGA aggregate 层面的 per-cancer permutation test 实质不可解释，建议正文明示而非仅加 caveat。** aggregate k_n 范围 3.0 × 10⁻⁵ 至 1.9 × 10⁻⁴，3/5 癌型 ω 在 k_f/10⁻⁴ 处饱和，且 null 为 fixed-panel（anti-conservative），全部 P > 0.9——该检验既无功效也无可信度，建议直接说明"该层检验不提供信息，结论以 pair-level cluster-bootstrap 为准"。位置：主稿 Methods "Permutation test"；第 84 行（Data- and design-specific constraints）。

**n6. Bergmann glia 端点类结论的重复表述口径。** 主稿第 26、56、58、78 行四处分别以不同基线（mouse 7.70 / brain-internal 9.73 / per-class 9.08 / studentized CI [5.76, 28.59]）重复了 Bergmann glia 的降级结论，表述不完全同步（第 56 行仍先给出 percentile CI [11.31, 16.14] 一类区间再行更正，Repro Guide 与 SI 3.2 亦残留旧区间）。建议全文统一引用 studentized 口径，清理残留旧值。位置：主稿第 56 行；SI 3.2；Repro Guide 5.3b。

## 前两轮修复的核实

**v49.10 B 组概念修复（HK 锚点有效性边界 + ω 为启发式指数而非选择度量）：到位。**
Introduction 第 4 段（第 13 行）单次、集中地陈述了核心假设（"the HK anchor is valid only where housekeeping expression remains constrained"），并预先给出失效情形（TCGA、IFN-β、模拟对抗场景）与降级规则（锚点受扰动时读分量、k_f + design-matched null 为 ordering 默认）。Discussion 第 72、74 行明确"heuristic index, not a formal measure of Darwinian selection"、"never as evidence of positive selection"，并正面写出与 Ka/Ks 的结构差异（无共享突变率的机制性相消）。Kang 演示（第 41 行）与 MELD/scDist 基准（第 43、85 行）为该边界提供了真实数据与模拟的双重演示。概念层面无遗留。

**v49.11 MK 三重对应重写：到位。**
Discussion 第 74 行给出完整对应：Ks ↔ k_n、Ka ↔ k_f、物种对 ↔ 两细胞群，"the mapping of McDonald–Kreitman-style contrasts, with a constrained rather than neutral reference class"；同时保留关键的不对称坦白（HK 锚点是最强约束的表达类而非中性标准，与 Ka/Ks 的分母角色"structurally rather than incidentally"相反）。SI 1.4 与之一致。类比现在既不越界也不空洞。

**v49.12 C2 增量诚实框架：基本到位，一处遗留。**
到位部分：(i) 候选筛查以全局裁决开头（第 63 行：期望 148.3 vs 观测 39、P = 1.0、min q = 0.520），目录自我定位为 "prioritized hypothesis list, not discoveries"；(ii) tier 依赖（79.5%/35.6%/16.9%/2.4%）明确标注为 post-hoc coherence check，且 Note 13 申报了 tier 规则与 per-pair P 值对同一 ω 的单调耦合；(iii) microglia 富集在 rule-matched null 下主动撤回（fold 2.30 → 0.31，P = 0.990）；(iv) thalamo-temporal 轴分析附 selection-rule-matched null 限定（绝对计数不极端、per-candidate 率集中），正文相应使用 "descriptive, exploratory characterization—not an inferential claim"；(v) Bergmann glia 端点在 studentized bootstrap-t 下正式降级为定性陈述。遗留：见次要问题 n4——正文目录篇幅与"无任何候选通过 FDR"的统计裁决仍不成比例，属呈现层而非方法层问题。
