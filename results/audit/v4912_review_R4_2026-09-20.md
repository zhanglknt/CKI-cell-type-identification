# 审稿意见 R4（TCGA/泛癌）

**审稿人角色**：肿瘤基因组学与 TCGA bulk RNA-seq；重点核查 CC 细胞系样本溯源、纯度混杂、泛癌反转的统计处置。
**版本**：v49.12（第三轮复审，2026-09-20）。

## 总评（3-5 句）

本轮 TCGA 部分是我三轮评审中最强的版本：泛癌反转以 cluster bootstrap（B=1,000）为主口径、LIHC 零结果按"4/5 CI 不含 1、方向一致、mapping 敏感性归档"的方式诚实处置；组成检验的两条 caveat（marker-panel 为噪声代理故衰减为下界、per-cancer 异质性反对单一解释）均保留；ESTIMATE 纯度论证链（admixture 与 k_n 负相关 → 只能减弱不能制造 TT k_n 升高；高纯半区五癌种比值全部上升）内部自洽；LUAD 驱动基因分层的因果措辞总体克制（EGFR 归因于 admixture 的表述基于调整后对比并披露了未调整 k_f 对比不显著）。上轮我要求的 CC 细胞系溯源与敏感性分析已补入：Methods 披露了 barcode 源码审计规则（第 14–15 位、ILSBio），第四控制剔 32 个 CC 样本后 LIHC 零结果不变（NN/TT 1.11 [0.93, 1.30] vs 1.10 [0.93, 1.29]），结论成立。但第四控制的**报告完整性不达标**（Methods 无实施细节、补充材料无章节、无脚本/输出路径），CC 样本对 LIHC 其他下游分析（admixture 半区、组成回归、严重度分层）的渗透未逐一交代，且发现一处主文数字与两种口径点估计均对不上（−16%）、一处 Note 8 措辞与自身数字方向矛盾。均为可修复的报告层面问题，不影响核心结论。

## 评分：8.0 / 10

## 推荐：Minor Revision

## 主要问题（编号）

**N1. CC 溯源审计不完整，未提供全量 barcode 源码分布。**
Methods 仅报告了 LUSC 矩阵中的 32 个 CC（ILSBio 肝癌细胞系）样本重标 LIHC 一个案例。一个完整的溯源审计应给出五个癌种全部样本（含正常样本）的 sample-source-code 分布表（FF/FFPE/CC/其他），说明审计规则是否系统性扫描了所有矩阵、是否存在其他异常源码或批次可疑样本，以及"29 个因 barcode 匹配/coverage 排除的样本"与该审计的关系。当前写法无法排除"只审计出了这一处"的选择性质疑。

**N2. 第四控制（剔 CC 敏感性）报告完整性缺失。**
主文 Results 报告了数字并标注 "(Methods)"，但 Methods 实际未描述该分析：剔除 32 个样本后 pair table 如何重建（TT 对是否重新抽样至 2,000 对上限、seed 是否一致）、k_n 比值如何重算，均无说明；补充材料没有对应章节、Supplementary Table、脚本或输出文件路径（同批 nc49_* 分析均有 script/output 引用，此处缺失）。按本文自设的可复现性标准（Reproducibility Guide + results/ 文件），这一控制目前不可复现、不可验证。要求补齐 Methods 段落、补充材料小节与脚本路径。

**N3. CC 样本对 LIHC 其他下游分析的渗透未逐一交代。**
第四控制只验证了 NN/TT 比值与 k_n 比值两个统计量，但 32/398（8%）的细胞系样本还可能进入：(a) ESTIMATE admixture 打分与高纯半区分析——细胞系纯度极高、几乎无基质/免疫信号，LIHC"低 admixture 半区"很可能富集 CC 样本，1.10→1.17 的提升可能部分由细胞系同质性（而非真实肿瘤纯度）驱动，且 admixture 与 k_n 的负相关（r=−0.23~−0.42）两端分布会被 CC 样本极端化；(b) Note 8 组成回归的 TT 对（CC 样本四 panel Δz 结构特殊）；(c) Edmondson 分级与 Cox 分析——若 CC 样本无 cBioPortal 临床标注则应自动排除，但作者未明说。要求逐一报告 CC 样本在各 LIHC 分析中的进/出，并对高纯半区分析给出剔 CC 版本的敏感性数字。

**N4. 主文 per-cancer 衰减区间 "−16% 到 +37%" 与两种口径的点估计均对不上。**
Linear 口径（主文声明的 authoritative caliber）Note 8 给出 per-cancer 衰减：LIHC +37.1%、KIRC +18.3%、BRCA −6.2%、LUAD −0.6%、LUSC −1.1%——下界为 −6.2%；softmax 归档口径给出 LUAD −4.3%、LUSC −2.7%、BRCA −4.0%——下界为 −4.3%。主文（Results 与 Discussion 两处）的 "−16%" 在两种口径中均不存在，疑似跨版本残留数字或笔误。请核对并统一为单一口径的区间。

**N5. Note 8 "absorb a substantial share" 的措辞与自身数字方向矛盾。**
Note 8 明确写 "composition covariates still absorb a substantial share of the tumor-pair coefficient in LIHC and KIRC"，但 LIHC（+37.1% / softmax +33.5%）与 KIRC（+19.6%）的衰减为**正值**，即加入组成协变量后 tumor-pair 系数**变大**（组成差异在掩盖而非解释 k_n gap）；真正被组成"吸收"的是负值方向的 BRCA/LUAD/LUSC。该句要么是符号约定未说明清楚，要么是方向写反。请修正措辞或明确衰减百分比的符号约定，并同步检查主文 "attenuates by −0.8% pooled" 的读者理解路径。

**N6. LUAD KRAS 对比的残差混杂与调整模型设定。**
(a) KRAS–WT 差异在 admixture + smoking（ever/never）调整后保留，但三个经典混杂未处理：TP53 共突变（LUAD 中 KRAS 突变与 TP53 突变强相关）、组织学亚型（浸润性黏液性腺癌富集于 KRAS）、pack-years（缺失 28%，仅描述性报告）。在声称 "KRAS-mutant tumors retained both components"（摘要级结论）前，至少应在 Discussion 增加一句残差混杂边界。(b) 协变量调整用 OLS 直接作用于原始 ω 尺度（metric ~ group + z-admixture），而同批 k_f 分析用 log k_f——ω 本身右偏（作者在 Statistics 节反复强调 skewness 2.22 等），两种成分的模型设定不一致；Δω +16.8 的 P=4.0×10⁻⁶ 建议给出 log-ω 版本的敏感性，或说明为何线性尺度可接受。

## 次要问题

1. **LIHC 零结果处置**：总体得当——方向一致、CI 含 1 如实报告、softmax 1.31 归档于 1.7 节、剔 CC 后 1.11 与高纯半区 1.17 的 CI 均仍含 1 且被如实说明。但 LIHC 同时是组成调整后系数变化最大的癌种（+37.1%）与效应量最 mapping-sensitive 的癌种（1.10 vs 1.31），建议在主文给 LIHC 一句集中 caveat（目前分散在三处）。"4/5 CI 不含 1" 未做多重性校正，作为描述性 pan-cancer 模式可接受，但建议注明。
2. **高纯半区论证链**：内部自洽（admixture 负相关 k_n → 高纯 TT ω 更低 → NN/TT 比值上升，五个癌种同向）。一个隐含假设是"肿瘤内 admixture–k_n 负相关可外推到 TT vs NN 比较"；直接证据（高纯半区）弥补了这一点，可视为闭环。但 ESTIMATE 分数与 k_n 同源于表达数据（shared measurement），且 CC 样本问题（N3）叠加其上。
3. **per-tumor ω 的构造**：含跨 driver 类 pair、组均值非不相交 pair 集合，已披露；KW 检验以肿瘤为独立单元，可接受。双突变体仅 2 例剔除，合理。
4. **EGFR "attributable to stromal/immune admixture"**（摘要用语）：基于调整后全 P>0.4 的消失，属合理的竞争性解释，但 "attributable" 是因果动词；结合 N6(b) 的模型设定问题，建议摘要改为 "consistent with / explained in the adjusted model by"。正文此处（"the apparent EGFR-mutant association was attributable to..."）同理。
5. **k_n 贡献 ~84% log-ω 差**的分解方法未在 Methods 说明（对数差按成分贡献分解的具体公式），建议补一句。
6. **剔 CC 后 TT k_n/NN k_n 的 CI 下限从 1.02 降至 1.00**，即 LIHC 的 k_n 升高在剔 CC 后已勉强贴住 1——主文说 "leaves the LIHC null result unchanged"，严格说 k_n 比值的显著性被削弱了（尽管幅度极小）。表述可以更精确。
7. 临床转化边界（Cox HR 1.075 [0.882, 1.309] P=0.475 明确降 SI、severity 分析主动披露 ω 梯度为 denominator-dominated、k_f 才随分级上升）：**处置克制，无过度承诺**，予以肯定。
8. 泛癌 reversal 的图 4 与补充表 11–17 交叉核对一致（3.13 节口径与主文一致：KW P=7.8×10⁻⁷、Dunn-Holm P=3.6×10⁻⁷、admixture 调整后 Δω +16.8 P=4.0×10⁻⁶ vs 联合 smoking+admixture +13.6 P=3.3×10⁻⁷ 为两个模型，无矛盾）。

## 上轮 CC 敏感性缺失修复核实

**结论：核心修复到位，报告完整性不足。**

1. **已核实到位的部分**：
   - Methods（Datasets, TCGA）新增溯源规则：按 TCGA barcode 第 14–15 位 sample-source code 审计，32 个源码 CC（ILSBio 肝癌细胞系）样本原随 LUSC 矩阵发布，重标为 LIHC，且声明"文中所有计数均已反映修正后的归属"（即 LUSC 534 个肿瘤已剔除这 32 个）。
   - Results "Four controls" 第四控制（主文 pan-cancer 节末尾）：剔除 32 个 CC 样本后 LIHC NN/TT = 1.11 [0.93, 1.30]、TT k_n/NN k_n = 1.34 [1.00, 1.88]（cluster bootstrap B=1,000），与全样本 1.10 [0.93, 1.29] / 1.35 [1.02, 1.88] 相比变化 <0.01 / 0.01，结论"LIHC 零结果非重标伪影"在数据上成立。CC 样本仅占 LIHC 肿瘤 8%，且高 admixture 的细胞系不太可能系统性抬高 TT k_n（其作用方向若非中性则是压低 TT k_n，即逆零结果方向），敏感性结果与该量级预期一致。
2. **未修复的部分**（对应 N1–N3）：
   - 第四控制在 Methods 无对应方法学描述（主文的 "(Methods)" 指针悬空），补充材料无章节/表/脚本/输出文件——不可复现。
   - 溯源审计未全量化（仅报告单一事件）。
   - CC 样本对 admixture 半区、组成回归、严重度分析的渗透未交代。

**处置建议**：N1–N3 补齐后即可接受；N4、N5 为文字/数字勘误，必修；N6 建议至少补 log-ω 敏感性与一句残差混杂边界。无需新增实验或重新分析主结论（除 N3 要求的剔 CC 版 admixture 敏感性外，该项为低成本复算）。
