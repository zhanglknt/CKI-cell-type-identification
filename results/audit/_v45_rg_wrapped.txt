0041| 2. CKI Algorithm Definition
0042| CKI decomposes transcriptomic divergence into two components:
0043| omega = k_f / k_n
0044| where:
0045| k_n  = JS(p_HK_A || p_HK_B)       ... baseline divergence rate
0046| k_f  = JS(p_ID_A || p_ID_B)       ... functional divergence rate
0047| and JS(P || Q) is the Jensen-Shannon divergence (base-2 logarithm, range [0, 1]):
0048| M        = 0.5 * (P + Q)
0049| JS(P||Q) = 0.5 * KL(P||M) + 0.5 * KL(Q||M)
0050| where KL(P||M) = sum_i [ P_i * log2(P_i / M_i) ]  for P_i > 0
0051| Both k_n and k_f use the same computational pipeline: (1) subset the pseudobulk expression vector to the relevant gene indices; (2) convert the vector to a probability distribution
0051|  by softmax normalization, p_i = exp(x_i - max(x)) / sum_j exp(x_j - max(x)) (cki/utils.py, ensure_probability_distribution; when the pseudobulk is the log1p of linear-scale aggreg
0051| ates, as in the brain pipeline, this is exactly equivalent to adding a +1 pseudo-count followed by L1 normalization on the linear scale, p_i = (y_i + 1) / sum_j (y_j + 1)); (3) com
0051| pute JS divergence between the two resulting distributions. This internal consistency (same metric, same normalization, same underlying expression space) ensures omega is self-cali
0051| brated.

0073| 3.2 Identity Genes (for k_f)
0074| Identity (functional) genes are defined as:
0075| Default (CKI): top-2,000 highly variable genes (HVGs; Scanpy seurat flavor), with HK genes explicitly excluded to maintain k_n/k_f independence (adapted to min(2000, 0.8 * n_total_
0075| genes)).
0076| Hybrid mode: per-pair k_n computed on the shared HK gene set (a single HK reference applied to all pairs, keeping k_n on a consistent scale across the atlas); per-pair k_f uses the
0076|  top-200 differentially expressed genes (ranked by |mean_diff| between the two groups), excluding HK genes.
0077| The default mode (global HVG 2,000) is used only for the Tabula Muris full pairwise matrix (03_full_matrix.py, 703 pairs, Fig. 2 heatmap). The hybrid mode (per-pair k_n with per-pa
0077| ir top-200 DE k_f) is used for all other reported analyses: Tabula Muris pilot analyses (calibration controls + validation, 02b_pilot_v2.py), Tabula Sapiens (human), TCGA, and the 
0077| Siletti brain atlas. In every dataset, k_n is computed per pair on the shared HK gene set: a sensitivity analysis contrasting this per-pair estimator with a global-k_n variant (k_n
0077|  computed once from the full gene-by-cell-type pseudobulk matrix) showed that brain k_n exhibits substantial cross-pair variability (CV = 97.52%) that is poorly captured by a globa
0077| l mean, and that the two estimators yield substantially different omega rankings (Spearman rho = 0.142; Supplementary Fig. S7). The parameter sweep (Supplementary Figure 1) confirm
0077| ed that the identity-only configuration (w1 = 1.0, w2 = 0.0) achieves the best cell-type discrimination without external pathway databases.

0149| 5. Statistical Testing
0150| 5.1 Permutation Test
0151| For each cell-type pair comparison, the null hypothesis H0: no functional divergence beyond baseline is tested via permutation:
0152|   1. Pool all cells from groups A and B.
0153|   2. For each of B iterations (B = 1,000 for all datasets):
0154|      a. Randomly permute cell labels.
0155|      b. Split into two groups of original sizes.
0156|      c. Recompute pseudobulks and omega.
0157|   3. Null distribution = {omega_perm[1], ..., omega_perm[B]}.
0158|   4. P-value (one-sided permutation test):
0159| p = (count(omega_null >= omega_obs) + 1) / (B + 1)
0160|   5. Effect size: SES = (omega_obs - mean_null) / std_null.
0161|   6. Null-distribution reference values: the one-sided critical value at alpha=0.05 is percentile(null, 95); omega_obs above this value rejects H0. The interval [percentile(null, 2
0161| .5), percentile(null, 97.5)] is the central 95% range of the null distribution (descriptive only) and is NOT a confidence interval for omega itself. Confidence intervals for omega 
0161| point estimates are computed separately by pair-level resampling (Section 5.3b).
