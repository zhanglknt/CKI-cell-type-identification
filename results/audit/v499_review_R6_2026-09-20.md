# Reviewer 6 (R6) — Editorial & Reproducibility Audit

**Manuscript:** "CKI is a Ka/Ks-inspired index quantifying functional divergence in single-cell genomics" (Wu & Zhang)
**Target journal:** Nature Communications (Methodology/Article track)
**Package audited:** MS.txt (218 lines), SI.txt (202 lines), CL.txt, GUIDE.txt (Reproducibility Guide), TABLE1.tsv
**Role of this review:** handling-editor + reproducibility audit (fit, completeness, compliance, reproducibility), not deep-science refereeing.
**Date:** 2026-09-20

---

## Summary

The submission presents CKI (ω = k_f/k_n), a Ka/Ks-inspired ratio index that normalizes identity-gene divergence (k_f) against a housekeeping-gene baseline (k_n), validated across simulation, Tabula Muris/Sapiens, Kang IFN-β PBMC technical replicates, a Siletti brain-atlas drift ladder and block-shuffle null, and TCGA. The package is statistically unusually self-critical (adversarial controls, circularity ablations, coverage-corrected CIs, design-matched nulls) and ships a serious reproducibility apparatus (pinned environment, Docker, Zenodo archive, 40-assertion spot-check script, pytest suite). Editorial fit for Nature Communications is good. However, the package as submitted has a **completeness failure in the Supplementary Information**: the SI table of contents advertises 19 Supplementary Tables, but the SI body delivers only Tables 1–4; Tables 5–19 are cited in the SI text yet have no captions or content. The MS back-matter statement compounds this by declaring "Supplementary Tables 1–4". I also found **five misnumbered cross-references** across MS/SI/Guide and several reproducibility-documentation gaps (no ordered run commands, undocumented seed exception, dangling parameter table). All defects are assembly-level and fixable without new science. **Recommendation: Minor Revision (mandatory corrections), 6.5/10.**

## Reproducibility assessment (GUIDE.txt)

**Strengths (credible and unusually complete):**
- Pinned verified environment: Python 3.14.4; numpy 2.4.6; scipy 1.17.1; scanpy 1.12.1; pandas 2.3.3; matplotlib 3.10.9; scikit-learn 1.8.0 (§1.1); CKI v0.5.0 editable install; Dockerfile; OS/RAM/disk/network requirements (§1.3).
- Data sources with concrete locators: TCGA Xena S3 URL with sizes, bundled probeMap, cBioPortal studies, GEO GSE96583 with exact file list, HRT Atlas shipped file (§1.4, §4).
- Seeds: global 42 with named exceptions 20260903 (notebooks 77/78/79) and 777000 (§1.4 line 39); matches MS Methods (line 123) and SI Note 12.
- Output manifest (§6) including explicit SUPERSEDED-file quarantine with authoritative replacements — exemplary provenance hygiene.
- Machine verification: `scripts/spot_check.py` (40 assertions on headline numbers), `pytest tests/` (7 regression tests), §7 checklist mapping claims → files.
- Algorithm definition with equations, per-dataset processing recipes, and runtime statement in MS (brain ≈ 72 core-hours; <5 min/pair).

**Gaps (should be fixed):**
1. **No ordered end-to-end run path.** The Guide lists scripts and outputs but never states "run these commands in this order" (no run_all / Makefile / per-analysis command lines). A reproducer must reverse-engineer the DAG from prose.
2. **Dangling parameter table.** §2.1 reads "All parameters used in the reported analyses:" followed immediately by "The above parameters, when used …" — the parameter table itself is absent from the extracted text.
3. **Undocumented seed exception.** SI Note 2 (line 150) reports the coverage study used "seed 20260905" (notebook 89); the Guide (line 39) and MS Methods (line 123) declare seed 42 with the *only* exceptions being 20260903 for notebooks 77/78/79. Either the declaration or the note is stale.
4. **Unpinned external tools.** pyaugur 0.1.0 (SI Note 14) and meld 1.0.2 (SI §3.11) are used for benchmarks but do not appear in the environment section/requirements.
5. **Runtimes per script largely absent** (only scattered values in SI notes: simulation ~1 min, ablation ~28 min); the 72-core-hour brain figure sits only in MS Methods.
6. Tabula Muris/Sapiens/brain download steps are less exact than Kang's (no file-level checksums or exact h5ad URLs; CELLxGENE collection ID given for brain only).

**Verdict:** credible path to bit-level reproduction of headline numbers via spot-check/pytest, but not yet a turnkey end-to-end recipe.

## Cover letter assessment

Length ~450 words across 5 paragraphs + 6 suggested reviewers with emails — appropriate length and structure. Fit-for-journal statement present ("fits Nature Communications' scope of computational methods validated on large-scale real data"). Claims match the manuscript's numbers exactly (0.00 vs 0.55–0.58; AUC 0.80; 0/30; 28.6% vs 35.7–45.2%; ladder 1.04→1.76→1.80; 1.10–2.46; 1.3–3.3-fold; KRAS/EGFR). Prior cover-letter overclaims were demonstrably scrubbed (GUIDE §5.5m: "orthogonal" and "confirmed baseline behavior" removed). One residual overclaim: **"CKI … is, to our knowledge, the first framework to make a principled separation of functional divergence from background drift in transcriptomic comparisons"** — a "first" novelty claim that is hard to defend categorically (reference-gene normalization and noise-floor baselines are long-standing, as the manuscript's own Discussion concedes); recommend softening to "a principled, design-testable separation". Reviewer suggestions are appropriate and conflict-free as stated.

## Writing quality

- **Hedge density / sentence bloat.** Paragraphs are extreme single-sentence constructs with nested parentheticals, e.g. MS line 26 (calibration) packs three CI systems, two baselines, and two supersession notes into one paragraph; MS line 80 (decision rules) runs >200 words. Effective but exhausting; the journal will ask for tightening.
- **Redundancies.** "limitations are addressed in the Discussion" appears verbatim twice (lines 13, 43); "hypothesis-generating" is used ~10 times; the 6.10/1.74 gradient caveat is restated in full at least four times (abstract, Results, Fig. 6 legend, Discussion).
- **Inconsistent terminology / naming.** The repository is named `CKI-cell-type-identification` while the manuscript insists CKI is "designed to detect state changes within a given cell type, **not to discriminate cell-type identity**" (line 82) and "is a divergence index, not a classifier" (line 73) — the branding contradicts the stated scope. "Conservative" for "conserved" in the Fig. 5(d) legend ("Top 5 conservative cell-type pairs"). Supp. Fig. 5 legend uses lowercase "panel a/panel b" vs "(a)/(b)" elsewhere.
- **Template artifacts.** SI §3.6/§3.7 contain placeholder-style cross-references: "(Results Section: Cancer analysis)", "(Results Section: CKI ranks cell types by cross-organ conservation)" instead of numbered sections; SI Note 9's "(Table 2 / Fig. 5)" (item D3 above); GUIDE §2.1's dangling "The above parameters".
- **Register quirks.** "the honest default", "the more honest statistic", "honest qualifications" — repeated moralizing register unusual for a methods paper; "This headline is an uncorrected upper bound" is fine once but the paper says it four ways.
- **Counting error.** "the lowest misreporting rate among the **four** continuous divergence metrics … versus 45.2% for raw JS, 44.1% for cosine, 40.6% for Spearman distance, 37.6% for k_f alone, and 35.7% for … k_n" (line 38) — five comparators listed (CL says "the other five").
- No systematic typos beyond the above; spelling is clean.

## Major concerns

1. **SI completeness failure — 15 of 19 advertised Supplementary Tables are missing from the document.** Tables 5–19 exist only as TOC lines; the SI text cites them for headline claims (Pan-Cancer NN/TT ratios, LUAD contrasts, Cox models, drift-ladder values, threshold sweeps), and MS line 197 misdeclares the SI contents as "Supplementary Tables 1–4". As submitted, key results referenced via "Section 3.12/3.13 + Supplementary Tables N" cannot be inspected in the package. Must be resolved before publication (either deliver Tables 5–19 or re-scope the TOC and MS statement).
2. **Five misnumbered cross-references** (Section D above), two of which send readers to the wrong main figure (Fig. 4 instead of Fig. 3) and one to the wrong bibliography entry (ref. 56 = bootstrap textbook cited for Augur). This pattern suggests the numbering layer was not regenerated after the v49 figure/table reshuffle; a full automated cross-reference pass is required.
3. **Reproducibility guide is not yet end-to-end:** no ordered run commands, a dangling parameter-summary table (§2.1), an undocumented seed exception (20260905 in SI Note 2 vs the declared 42/20260903 policy), and unpinned benchmark dependencies (pyaugur, meld). For a Methodology-track paper whose central selling point is reproducibility, these gaps are material.

## Minor concerns

1. Abstract is 198/200 words (passes the audit bar; consider trimming toward the ~150-word Nature Portfolio norm).
2. No keywords line (optional at this journal); ORCID missing for first author.
3. Data availability section lacks the GitHub URL/Zenodo DOI (present only under Code availability) — cross-link them.
4. "Four continuous divergence metrics" vs five comparators listed (MS line 38); Fig. 3a/5/6 panels uncited; Supp. Fig. 5 legend style inconsistent ("panel a", "conservative").
5. SI §1.6 states pseudobulk "minimum of 10 cells per group", contradicting the ≥20-cells-per-entry filter stated in MS Methods and SI §4.1/4.2.
6. Repository name (`cell-type-identification`) conflicts with the manuscript's explicit not-a-classifier scope statement.
7. Cover letter's "first framework" novelty claim should be softened.
8. MS Methods cites "the Reproducibility Guide, Section 1.1 of the Supplementary Information" — ambiguous, since the SI proper has its own Section 1.1 (JS divergence); the Guide is a separate document.
9. pyaugur/meld benchmark provenance: results rely on a "Python approximation of scDist" and an unverified port — adequately disclosed, but the journal may ask for the disclaimer in the main text (it is there) and in the figure legend (it is not).

## Score

**6.5 / 10 (strict).** Science-as-audited and reproducibility infrastructure are strong (would be 8+); the submission-package quality — missing 15 supplementary tables, five wrong cross-references, a non-executable-by-itself guide — is below the bar Nature Communications applies at acceptance and costs 1.5–2 points.

## Recommendation

**Minor Revision** (mandatory corrections before publication). All required fixes are editorial/assembly-level: (i) deliver Supplementary Tables 5–19 or reconcile the SI TOC and the MS line-197 statement; (ii) correct the five misnumbered cross-references and run a full numbering regeneration; (iii) add an ordered run-command sequence, the §2.1 parameter table, per-script runtimes, and the missing seed exception to the Reproducibility Guide. No new experiments or re-analysis are required. If the journal treats missing SI content as a bar to sending the paper to reviewers, triage as "revise before review".
