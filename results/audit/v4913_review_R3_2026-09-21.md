## Minor concerns

**M1. Monte-Carlo precision of permutation P near the floor (SI 3.13, MS Fig. 4b text).**
The archived KRAS–EGFR permutation P is 0.00340; the text states "P = 0.003". More importantly, at B = 10,000 the Monte-Carlo standard error of a P ≈ 0.004 estimate is ≈ 6 × 10⁻⁴: my independent re-run of the same contrast under a fresh RNG stream gave P = 0.0049 (the archived 0.0034 is recovered only by replaying the exact seeded stream). The conclusion is unaffected, but the last significant digit of these permutation P-values is not stable. Suggest reporting them with one fewer digit (e.g. "P ≈ 0.003", or stating the B = 10,000 MC resolution), as is already done implicitly for the KW floor value.

**M2. Pair-level P-values in the composition check ignore dyadic dependence (SI Note 8).**
The |Δz| contrasts (P = 3.57 × 10⁻¹³⁷, 1.28 × 10⁻⁶⁶) and the Spearman P-values (P < 10⁻³⁰⁰; per-cancer down to 7.7 × 10⁻¹⁹) treat 10,000 TT pairs as independent, yet each tumor participates in a median of 4–11 pairs, so these P-values are anti-conservative by a large factor. The authors themselves adopt exactly this caveat elsewhere ("pair-level Mann-Whitney P-values, which ignore dyadic dependence between pairs, are reported as descriptive only", MS Results). The substantive inference in Note 8 — the attenuation estimate with its sample-level cluster-bootstrap CI — is already at the correct caliber, so this is only a labeling issue: please add the same "descriptive only" qualifier to the composition P-values, or note that effect sizes (1.305/1.216-fold; ρ = 0.364) are the intended content.

**M3. Composition cluster bootstrap uses B = 200 (SI Note 8, Guide 5.8b).**
The headline pooled CI [−5.0%, +2.3%] is quoted in the main text, but percentile endpoints at B = 200 carry ~1%-resolution Monte-Carlo noise, and all other TCGA bootstraps in the paper use B = 1,000. A rerun at B = 1,000 would harmonize the calibers; cost is trivial.

**M4. log-ω bootstrap CI not archived (SI 3.13).**
results/nc49_tcga_luad_logomega_sensitivity.csv records the exponentiated KRAS/WT ratio (1.185) but not its bootstrap CI; [1.12, 1.26] exists only in notebook stdout. I reproduced it independently ([1.117, 1.257], seed 42), so the claim is sound — but please write the CI into the CSV for auditability.

**M5. Observation (no action required).** The pooled attenuation (−1.3%) masks strong per-cancer heterogeneity (LIHC +31.7% [+21.0%, +45.3%], KIRC +19.4% [+14.7%, +23.9%], both CIs excluding 0; BRCA −15.9%). The text now states this explicitly in both MS and Note 8 ("the pooled near-zero estimate still masks this heterogeneity"). This is the right level of candor.
