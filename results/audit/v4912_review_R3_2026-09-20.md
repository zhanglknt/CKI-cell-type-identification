## 总评（3-5 句）

本轮统计核心已达到发表水准：上轮 N1（seed 未申报）、N2（softmax/linear 口径混用，主稿与补充材料层面）、N3（阈值扫描梯度缺值）三项均已在 MS/SI 层面修复且交叉一致；studentized bootstrap-t 的方法学描述（influence-function multiplier sandwich SE、log 尺度 delta 方法、B=5,000 seed 20260905、Monte Carlo 覆盖 0.953/0.951）准确充分，替代 under-covering 的 percentile 区间有理有据；多重检验的 BH 复算全部吻合、tier 依赖性明确降级为 post-hoc coherence check 并披露数学耦合告警，处理规范。但独立复算发现两处新的溯源缺陷：复现指南第 5.7 节两处仍全文引用已被弃用的 softmax 口径组成检验数值（ρ=0.387、−0.5% [−3.2%, +2.6%]）且无任何 superseded 标签，与 MS/SI 声明的 authoritative linear 口径直接冲突；MS Discussion 引用的组成差异效应量（|Δz| 1.30/1.23-fold、P=8×10⁻¹⁴⁰/3×10⁻⁷⁴）在 SI 与 Guide 的任何归档口径中均不存在对应数值。二者均为文档一致性而非结论正确性问题，修复成本低，但以本刊标准必须修复后方可接受。

## 主要问题（编号）

### N4（新）：Reproducibility Guide 5.7 节残留 softmax 口径组成检验数值，未加 superseded 标签——三文档口径链断裂

Guide 第 5.7 节两处（对应全文行 203 与 285）详细引用的组成检验结论仍是 softmax 口径旧值：

- "k_n correlates with the four-panel composition difference (Spearman rho = **0.387** pooled; 0.23-0.52 per cancer type)"
- "attenuates the tumor-pair coefficient by only **-0.5% pooled (95% CI [-3.2%, +2.6%]**; per-cancer BRCA -14.0%, LUSC -9.7%, LUAD -2.3%, KIRC +19.6%, LIHC +33.5%)"

而 MS（Results 四控制段 + Discussion 组成检验段）与 SI Note 8 的 linear-normalization update（authoritative caliber）报告的是：**−0.8% pooled（cluster-bootstrap median −1.2%，95% CI [−4.1%, +2.6%]；per-cancer −16% 至 +37%）与 ρ=0.355 pooled（0.146–0.492）**。Guide 5.8b 虽列出 linear 组成检验脚本（notebooks/86_tcga_composition_linear_norm_v44.py）却未给出任何数值。

后果：复现者按 Guide 5.7 的 seed/流程重跑并对照，将得到 ρ=0.387 与 −0.5% [−3.2%, +2.6%]，与 MS/SI 引用的 0.355 与 −0.8%/[−4.1%, +2.6%] 均不匹配，且无从得知何者为错。这是上轮 N2（口径混用）同一类缺陷在 Guide 中的残留实例——MS 与 SI 已修，Guide 未同步。Guide 内部亦自相矛盾：其 TCGA 主分析条目（"NN/TT ratio ... under the linear probability mapping ... legacy median/softmax caliber is archived as a sensitivity analysis"）已切换 linear 口径，唯独 5.7 组成检验两处未动。

**要求**：Guide 5.7 两处改为 linear 口径数值（或明确加注 "softmax caliber; superseded by the linear-normalization update (authoritative), see 5.8b"），并在 5.8b 补报 linear 组成检验的关键数值（−0.8%、[−4.1%, +2.6%]、ρ=0.355 及 per-cancer 区间），使三文档口径链闭合。

### N5（新）：MS Discussion 引用的组成差异效应量无法溯源——|Δz| 1.30/1.23-fold 与 P=8×10⁻¹⁴⁰/3×10⁻⁷⁴ 在任何归档口径中均不存在

MS Discussion 组成检验段报告："median |Delta z| **1.30-fold** higher for the three-panel composite and **1.23-fold** with the myeloid panel included; **P = 8 × 10⁻¹⁴⁰ and 3 × 10⁻⁷⁴**"。

逐一对照两处归档：

| 统计量 | MS 引用 | SI Note 8 softmax 段（已标 superseded） | SI Note 8 linear 更新段（authoritative） |
|---|---|---|---|
| 三面板 \|Δz\| | 1.30-fold，P=8×10⁻¹⁴⁰ | 1.33–1.46-fold（all P < 10⁻³⁰⁰） | 未报告 |
| 四面板 \|Δz\| | 1.23-fold，P=3×10⁻⁷⁴ | 1.24-fold（median 0.834 vs 0.673；P=9×10⁻⁷⁷） | 未报告 |

MS 数值既不等于 softmax 归档值，也未见诸 linear 更新段（该段只报回归衰减与 ρ）。两种可能：(a) 系 linear 口径下重算的 |Δz|——则 SI Note 8 linear 段与 Guide 5.8b 必须补报这些数值；(b) 系对 softmax 段的不同汇总口径（如三面板 pooled composite vs SI 的 per-panel 区间）——则必须在文中定义汇总方式并解释 P 值差异（pooled P=8×10⁻¹⁴⁰ 反而小于 per-panel 的 <10⁻³⁰⁰，方向上存疑）。无论哪种情形，当前状态下读者无法复核这两个效应量。附带问题：linear 口径 ρ=0.355 pooled 未报告 P 值或 CI（softmax 口径的 ρ=0.387 有 P<10⁻³⁰⁰），显著性陈述不完整。

**要求**：明确 |Δz| 1.30/1.23-fold 与两个 P 值的口径与出处，并在 SI Note 8（或 Guide 5.8b）补报对应归档值；同时为 linear 口径 ρ=0.355 补 P/CI。

## 次要问题

1. **（N6）MS 类均值 CI 列表的 B 值归属易误读**。Results 脑区段："Region-clustered bootstrap 95% CIs for the class-level means (**B = 2,000**; Methods): astrocytes [75.66, 89.53], ... Bergmann glia [5.76, 28.59] (**studentized bootstrap-t**; the earlier percentile interval under-covers at 7 clusters...)"。括号内 B=2,000 管辖的是前述 percentile 区间，Bergmann 的 studentized 区间实为 B=5,000（Methods/Statistics 节、SI Note 2），两种 B 并列于同一句，建议拆分表述或加注 B=5,000。
2. **（N7）Bergmann glia ω_cal 联合区间未按 SI Note 2 自定原则统一处理**。SI Note 2 声明 studentized bootstrap-t "is therefore the recommended replacement for **every** statistic resting on ≤ 7 region clusters"，但 Bergmann glia ω_cal=1.49 的 joint 95% CI [0.99, 2.12]（两阶段 region-clustered + split-half 联合 bootstrap，B=5,000）仍是 percentile 型区间，同样依赖 7 个 region cluster。此处结论方向安全（区间已含 1；若真区间更宽仍含 1），但口径上与自设原则不一致，建议补一个 studentized 版本的敏感性或说明联合两阶段设计下 studentized 不可行的原因。
3. **（N8）阈值 100 nuclei 处的类别剔除不完全透明**。"the eight retained classes exclude Bergmann glia" 只点名一个被剔除类；另一被剔除类（推测为 vascular cells）未点名。若 vascular cells 仍在，端点梯度本可对 vascular 计算（两者均值同为 13.56），"undefined" 的成立依赖第二个剔除类也是端点类。请 SI Table 19 点名两个被剔除类及各阈值下端点定义。另外 SI 全文提供的 Table 19 仅为标题行，6.60/4.12 两个梯度值在提交文本材料中无法独立核对（仅见于 MS），请确保正式 SI 表格含这些数值。
4. **（N9）SI Note 2 覆盖模拟的数据生成过程（DGP）未描述**。Monte Carlo 覆盖研究（2,000 模拟 × B=999）报告 percentile 0.876/0.873、wild 0.816/0.806、studentized 0.953/0.951，但未说明 6–7 cluster 数据如何生成（仅定性提到 skewness 与 2⁶–2⁷ 符号组合粗糙性）。studentized 区间在极少 cluster 下可能不稳定（重抽样 SE 近零时区间发散），覆盖结论的可信度依赖于 DGP 是否捕捉真实依赖结构，请补一句 DGP 描述。
5. **（措辞）MS 阈值扫描句自相矛盾**："large classes change ≤ 2% in mean ω (microglia +4.8%)"——括号内 +4.8% 超出前述 ≤2% 上限。应改述为 "≤ 2% for all large classes except microglia (+4.8%)" 之类。
6. **（建议）组成检验 cluster bootstrap B=200**。pooled 区间 [−4.1%, +2.6%] 端点的 Monte Carlo 误差 1–2 个百分点已在 SI 披露（合格），但鉴于该区间是"组成解释很少"这一关键结论的支撑，且 LIHC +37.1% [+27.1, +51.5]、KIRC +18.3% 等异质性大，建议将 B 提升至 ≥1,000（与泛癌 CI 的 B=1,000 对齐）以收紧端点 MC 误差，或至少在 MS 中提及 B 与该误差。
