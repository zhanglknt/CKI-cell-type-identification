0013| Background
0014| Comparing two cell populations is among the most common tasks in single-cell analysis. Researchers typically choose a standard metric: Euclidean distance, cosine similarity, Pearso
0014| n or Spearman correlation, or Jensen-Shannon divergence. These metrics are convenient, but they treat all gene expression differences equally.
0015| Not all expression changes have the same biological meaning: a twofold change in GAPDH may reflect technical noise, whereas a twofold change in a transcription factor may reflect a
0015|  functional state shift, and standard metrics cannot tell these apart. The problem is acute in large single-cell atlases [1], where donor- and batch-level variation often dominates
0015|  over cell-type identity. Methods such as Harmony [2], scVI [3], and SATURN [4] remove such nuisance variation [5], but a key question remains: how much of the difference between t
0015| wo populations reflects functional adaptation rather than neutral drift?
0016| This question mirrors one addressed in molecular evolution. The Ka/Ks ratio (dN/dS) distinguishes nonsynonymous changes (Ka, which alter the protein) from synonymous changes (Ks, l
0016| argely silent) [6,7], using synonymous sites as an internal baseline so that the ratio reveals selection. While CKI does not share Ka/Ks鈥檚 formal mathematical properties (notably t
0016| he shared mutation rate that cancels in the ratio; see Discussion), it adopts an analogous heuristic logic for transcriptomic comparisons.
0017| CKI defines two rates: a baseline divergence rate k_n, estimated from housekeeping (HK) gene expression, and a functional divergence rate k_f, estimated from cell-type identity gen
0017| es. The ratio 蠅 = k_f/k_n quantifies baseline-normalized functional divergence: values close to the equivalent-population calibration baseline (established empirically within each 
0017| dataset; see Results) indicate baseline-consistent differences, values far above indicate functional divergence exceeding baseline variation, and values far below indicate strong f
0017| unctional constraint. The scope of 蠅 is bounded by a single central assumption, stated here once and quantified empirically throughout: the HK anchor is valid only where housekeepi
0017| ng expression remains constrained. Functional signal located on HK genes is invisible to 蠅 by construction, and in disease or strong-perturbation contexts the anchor itself shifts鈥
0017| 攈ousekeeping dysregulation and composition change in cancer (TCGA, below), IFN-尾 stimulation of housekeeping genes in the perturbation demonstration (below; simulated adversarial s
0017| cenarios in Additional file 1: Note 3.12)鈥攊nflating the denominator and deflating the ratio. In such regimes 蠅 must be read alongside its components, and k_f with a design-matched 
0017| null is the honest default for ordering claims (Results; Limitations). CKI 蠅 is a heuristic index, not a formal measure of Darwinian selection; interpretation is anchored in the em
0017| pirical distribution of 蠅 within each analysis rather than in fixed ratio cut-offs or claims about selection regimes (see Discussion).
0018| We evaluated CKI across four scales. First, we calibrated CKI on Tabula Muris mouse data [8]: random splits of the same cell population yield 蠅 above 1 (empirical calibration basel
0018| ine 7.70, 95% CI [7.37, 8.02]). Second, in Tabula Sapiens human data [9], CKI 蠅 is negatively correlated with all four standard distance metrics; a decomposition analysis showed th
0018| is association is partly driven by the k_n denominator (k_n is itself strongly positively correlated with the standard metrics), so 蠅 is a composite of numerator and denominator in
0018| formation rather than a fully independent dimension (see Results). Third, applied to TCGA cancer data [10,11], CKI suggested that tumors appear more transcriptionally homogeneous t
0018| han adjacent non-tumor tissues at bulk resolution (an exploratory observation; see Results for caveats). Fourth, in a human brain single-nucleus atlas [12], we measured how non-neu
0018| ronal cell classes differ across brain regions, quantifying a 6.10-fold regional differentiation gradient and screening for anomalously similar cell-type/region-pair candidates; be
0018| cause no candidate survived false-discovery-rate correction under a strict block-shuffle null preserving the cell-type-by-region design, we present the brain candidates as hypothes
0018| is-generating signals for future lineage-tracing validation. The human, pan-cancer, and brain analyses are complemented by mouse Tabula Muris calibration and ground-truth simulatio
0018| n analyses throughout.

0020| Decomposing transcriptomic variation
0021| CKI takes two cell populations as input, each represented as a pseudobulk expression vector (mean expression across its cells). The computation has three steps, all using the same 
0021| metric (Jensen-Shannon divergence) on the same expression matrix, so the ratio is internally calibrated (Fig. 1).
0022| Step 1: Compute the baseline divergence rate k_n. We restrict the pseudobulk vectors to housekeeping (HK) gene indices and add a +1 pseudo-count followed by L1 normalization; k_n i
0022| s the JS divergence between the two HK-gene probability distributions. Because HK genes should not differ systematically between biologically equivalent populations [13], k_n captu
0022| res baseline noise: technical variation, stochastic bursting, and individual-level physiological differences.
0023| Step 2: Compute the functional divergence rate k_f. We restrict the pseudobulk vectors to identity gene indices鈥攇enes that define cell-type-specific functions. In the default confi
0023| guration (Tabula Muris full pairwise matrix, Additional file 1: Fig. S1), identity genes are the top-2,000 highly variable genes (HVGs; Seurat flavor), excluding HK genes; for the 
0023| mouse pilot calibration and all other analyses (human Tabula Sapiens, TCGA, brain atlas), k_f uses the top-200 differentially expressed genes (ranked by absolute mean difference) f
0023| or that specific pair and k_n is computed per pair on the shared HK gene set, HK genes excluded throughout. k_f is the JS divergence between the two identity-gene probability distr
0023| ibutions. Because the k_f genes are selected per pair from the observed difference itself, k_f magnitudes are inflated relative to non-circular selection (median 1.61-fold versus a
0023|  leave-pair-out panel) while rankings are essentially preserved (Spearman 蟻 鈮?0.92鈥?.94 across schemes); absolute k_f鈥攁nd therefore absolute 蠅鈥攁re upper-bound, scheme-specific esti
0023| mates (fixed gene-panel ablation, Results).

0025| A parameter sweep on Tabula Muris mouse data (703 cell-type pairs across 6 organs) showed that adding pathway enrichment scores to k_f does not improve performance: the identity-on

0025|  expression into constrained baseline and identity gene sets suffices, without external pathway databases.

0079| Discussion
0080| CKI reframes transcriptomic comparison鈥攆rom measuring absolute distance to quantifying functional divergence relative to an internal baseline鈥攂ut this is better described as a reco
0080| mbination of established ideas than a conceptual shift. Reference genes have long anchored normalization and quality control in expression measurement: qPCR normalization by geomet
0080| ric averaging of validated internal control genes [31], and the constrained-variance property of housekeeping genes has been characterized at the genomic level [13,32]. The idea th
0080| at an intrinsic, gene-property-dependent noise floor can serve as a baseline has likewise been central to the transcriptional-noise literature [33-35], which showed that expression
0080|  variance is reproducibly gene-specific. CKI鈥檚 specific contribution is to combine these ingredients鈥攁 constrained reference set, a functional panel, and their divergence ratio鈥攊nt
0080| o a per-comparison, design-testable index with an explicit split-half calibration and a design-matched permutation null, rather than to introduce a new concept. The key assumption 
0080| is that housekeeping (HK) genes are under stabilizing selection that constrains their expression variance across conditions, making them a practical constrained baseline against wh
0080| ich functional divergence can be measured. This decomposition is heuristically inspired by Ka/Ks analysis, but CKI is a heuristic index rather than a formal measure of selection: u
0080| nlike Ka/Ks鈥攚here a shared mutation rate cancels mathematically, leaving a pure selection signal鈥擟KI uses empirically defined HK genes as the baseline, lacking a comparable mechani
0080| stic cancellation. The empirical calibration (split-half equivalent populations; 50 replicates across six control populations) yielded a mean 蠅 = 7.70 (95% CI [7.37, 8.02]; the leg
0080| acy six-split estimate 6.67 is consistent with it), indicating that k_f systematically exceeds k_n even for identical populations due to identity-gene selection. We therefore use 蠅
0080| _cal = 蠅 / 7.70 as the operational scale, interpreting 蠅_cal relative to the empirical equivalent-population distribution rather than against fixed cut-offs: values well below the 
0080| calibrated baseline suggest functional constraint and values well above it enhanced divergence鈥攏ot as claims about Darwinian selection regimes, and with the caveat that the baselin
0080| e is dataset-dependent (Results).
0081| CKI is a divergence index, not a classifier鈥攁nd this is by design. Classifying cell types from transcriptomic data is largely a solved problem; CKI answers a complementary question
0081| : regardless of cell-type labels, how much functional divergence separates two populations, relative to their shared baseline? The negative correlation with all standard metrics in
0081| itially suggested complementary information content, but the decomposition analysis showed this association to be partly a denominator effect (k_n is itself strongly positively cor
0081| related with the standard metrics), so 蠅 should be understood as a composite of numerator and denominator information rather than a fully independent signal dimension.
0082| The Ka/Ks analogy is heuristically productive but has technical limitations that distinguish CKI from formal molecular evolution models. Ka/Ks operates on DNA sequence alignments w
0082| ith explicit codon models, whereas CKI uses continuous expression vectors without a substitution model; HK genes are defined empirically (high detection rate, low CV) rather than m
0082| echanistically (synonymous sites in Ka/Ks), and their expression variance could reflect regulatory constraints rather than pure neutral drift鈥攕ensitivity analysis with alternative 
0082| low-variance gene sets (r > 0.95) partially mitigates this concern. CKI also lacks a formal phylogenetic framework (e.g., Ornstein-Uhlenbeck models), and 蠅 is computed on different
0082|  gene sets per comparison, limiting absolute cross-comparison interpretability: users should compare 蠅 ranks rather than absolute values across datasets.
0083| CKI complements rather than replaces existing methods. SAMap [36] and SATURN [4] excel at cross-species alignment; CACIMAR [37] provides conservation scoring that could be reinterp
0083| reted through the CKI lens. However, we did not quantitatively benchmark CKI against these specialized methods, as they address different questions (cross-species alignment vs. wit

0088| When to use CKI versus standard metrics
0089| CKI and standard metrics answer different questions, and choosing between them can be reduced to a few practical rules. Use CKI when the question is relative: is the functional div
0089| ergence between two populations larger than what their own housekeeping baseline varies by, within the same dataset and gene-selection scheme? CKI then offers (i) a normalized, int
0089| erpretable scale (蠅 relative to the split-half calibration), (ii) higher discrimination than raw distances for strong perturbations (simulation AUC 0.80 for 蠅 versus 0.72 for k_f, 
0089| 0.64 for raw JS, and 0.58 for cosine鈥攗nder the simulation鈥檚 HK-anchored neutral-drift definition and top-200 gene selection; Results), and (iii) a specificity-first screen: with a 
0089| design-matched permutation null, a significant 蠅 rejects label exchangeability under that null, and attribution to functional divergence further requires excluding library-level co
0089| nfounders (batch, donor, dissection order, RNA quality; Limitations); drift on the anchor is the null hypothesis by construction, and functional signal on the anchor is invisible t
0089| o 蠅. Before trusting fine-grained 蠅 orderings, diagnose the denominator: if per-pair k_n itself lies in the extreme tail of its own null distribution, or k_n correlates with techni
0089| cal covariates (composition estimates, batch, RNA-quality proxies), report k_f (or SES(k_f)) with the design-matched null directly rather than the ratio. In the real data analyzed 
0089| here, 蠅 orderings were predominantly denominator-driven (brain class-mean 蟻(蠅, k_n) = 鈭?.73; TCGA NN/TT inversion and severity gradients predominantly denominator effects; cross-or
0089| gan cell-type ranking not reproduced under k_f-only; Additional file 1: Note 3.16), so the honest default for ordering claims is k_f plus a design-matched null, with 蠅 reserved for
0089|  its specificity-first property鈥攔ejecting HK-anchored neutral drift鈥攔ather than for ranking. A real perturbation demonstration (Results) supports this boundary within the limits of
0089|  its lane-confounded design: IFN-尾 stimulation raises k_n itself 1.2鈥?.7-fold above the donor-drift level, and where it does so most strongly (CD14+ monocytes) the 蠅 AUC for separa
0089| ting perturbation from donor drift falls to 0.55 while k_f retains 0.98. Use standard metrics when any of the following hold: absolute distances with cross-dataset meaning are requ
0089| ired (蠅 does not transfer across datasets or schemes鈥攃ompare ranks only); the task is classification or clustering of cell types (a largely solved problem where normalization adds 
0089| little); weak-to-moderate effects must be detected at atlas scale (CKI鈥檚 sensitivity is bounded by permutation resolution and multiplicity, as the brain analysis illustrates); or t

0099| Conclusions
0100| CKI adapts the baseline-normalization logic of Ka/Ks to single-cell transcriptomics, decomposing population divergence into a housekeeping baseline rate (k_n) and an identity-gene 
0100| functional rate (k_f). Across simulation, calibration, cross-organ, pan-cancer, and brain-regional analyses, we showed that 蠅 rankings carry reproducible biological signal while ab
0100| solute 蠅 values remain scheme- and dataset-specific, that statistical claims at atlas scale require nulls respecting the experimental design, and that the absence of FDR-significan
0100| t candidates is itself an informative bound on what adult transcriptomes alone can support. CKI is released as an open-source Python package with a fully reproducible analysis pipe
0100| line, and we anticipate its use as an interpretable complement to standard distance metrics in comparative single-cell analyses.
0101| Methods
0102| CKI computation
0103| We normalize raw count matrices to 10,000 counts per cell and apply log1p transformation [42]. Pseudobulk vectors average expression across cells sharing the same cell-type annotat
0103| ion (at least 20 cells per entry (pseudobulk group); at least one donor/mouse contributing at least 10 cells). Housekeeping (HK) genes are loaded from the HRT Atlas v1.0 reference 
0103| [13] (1,130 human-mouse conserved HK genes; mouse ortholog column for mouse datasets, human column for Tabula Sapiens, TCGA, and the brain atlas). The package also supports data-dr
0103| iven auto-detection (detect_housekeeping_genes(); combined detection-rate and CV criterion, use_reference = False), but all reported analyses use the pre-specified reference.
0104| For populations A and B with pseudobulk vectors 蔚_A and 蔚_B, each vector is normalized to a probability distribution before Jensen-Shannon (JS) divergence computation by a softmax 
0104| over log-transformed values, which in count space is exactly the operation of adding a +1 pseudo-count followed by L1 normalization: p_i = (c_i + 1)/危_j(c_j + 1), where c denotes t
0104| he pseudobulk count. The aggregation order differs across datasets and must be distinguished: the brain pipeline applies log1p after averaging counts, softmax(log1p(mean counts)), 
0104| matching the count-space formula exactly, whereas the mouse (Tabula Muris pilot) and human (Tabula Sapiens) pipelines average per-cell log1p values and normalize afterwards, softma
0104| x(mean(log1p)). This difference plausibly contributes, alongside dataset scale and gene-selection effects, to the non-transferability of the dataset-specific calibration constants 
0104| (Results). Then k_n = JS(norm(蔚_A[H]), norm(蔚_B[H])), where H is the set of HK gene indices; k_f = JS(norm(蔚_A[I]), norm(蔚_B[I])), where I is the set of top-2,000 highly variable g
0104| enes (HVGs; Seurat flavor) excluding HK genes; 蠅 = k_f/k_n, with JS divergence [43] using the base-2 logarithm (range [0, 1]). To guard against division by near-zero k_n, the packa
0104| ge exposes an optional denominator floor (kn_floor); the package default (kn_floor = 0) applies only a positivity guard, used by all reported single-cell analyses, so no reported s
0104| ingle-cell 蠅 was capped (minimum observed per-pair k_n: 1.1 脳 10鈦烩伌, mouse; 6.3 脳 10鈦烩伌, human; 9.2 脳 10鈦烩伒, brain; only 1 of 31,764 pairs had k_n below 1 脳 10鈦烩伌, and these values
0104|  entered 蠅 uncapped). The TCGA bulk analysis is the sole exception and applies kn_floor = 1 脳 10鈦烩伌, because pseudobulk averaging across millions of cells compresses HK gene varian
0104| ce and drives aggregate k_n toward zero (see Results). One property of this mapping must be made explicit for TCGA: applied to log2(TPM + 1) values, the softmax is mathematically e
0104| quivalent to p_i 鈭?(TPM + 1)^{1/ln 2}鈥攁n implicit power transformation of the counts that was not disclosed in earlier versions of this pipeline. We therefore recomputed every TCGA
0104|  analysis with the linear normalization p_i = (TPM + 1)/危_j(TPM_j + 1): all qualitative conclusions were unchanged (the NN > TT 蠅 reversal preserved in 5 of 5 cancer types; kn_floo
0104| r saturation 0; all severity-gradient directions preserved), with full side-by-side results in Additional file 1.
0105| A note on package parity: all hybrid-scheme analyses reported in this paper (mouse pilot, Tabula Sapiens, TCGA, brain atlas) select the k_f genes of each pair as the top-200 genes 
0105| ranked by the absolute pseudobulk difference. The released package鈥檚 func_method = "pairwise_de" option instead runs a two-directional Wilcoxon test and yields a different gene set
0105| ; the reported abs-diff scheme is provided exactly as func_method = "pairwise_absdiff" in package version 0.4.8. All 蠅 values reported here were computed with the abs-diff scheme. 
0105| The package鈥檚 permutation test (bootstrap_test()) reproduces the reported null by default: reselect_identity = True holds the HK set fixed while re-selecting the k_f set at every p
0105| ermutation under the same per-pair rule as the observed value; the legacy fixed-gene-set null remains available as reselect_identity = False and is anti-conservative relative to re
0105| -selection (cf. the TCGA fixed-panel caveat).
0106| Dimensionality invariance of JS divergence
0107| Because k_n is computed on ~1,130 HK genes and k_f on 200鈥?,000 HVG genes, we verified that JS divergence is not systematically biased by gene set dimensionality. A simulation of 2
0107| ,000 random Dirichlet distribution pairs across dimensions 50鈥?,000 showed mean JS divergence effectively constant (0.155鈥?.159, ratio = 1.001 between d = 1,130 and d = 2,000; Addi
0107| tional file 1: Fig. S12). The systematic inflation of k_f relative to k_n (蠅 = 7.70 for equivalent populations) therefore arises from HVG selection bias rather than dimensional mis
0107| match; the calibrated omega (蠅_cal = 蠅 / 7.70) absorbs this bias into the empirical baseline, and the permutation null鈥攃onstructed using the same gene sets鈥攅nsures internal consist
0107| ency.
0108| Permutation test
0109| Statistical significance was assessed with permutation tests whose exchangeability unit and gene-selection handling follow the structure of each dataset. For the mouse pilot, Tabul
0109| a Sapiens, and TCGA per-cancer analyses, labels were permuted between groups (cell labels, or tumor/normal labels across bulk samples; B = 1,000); pseudobulks were recomputed after
0109|  each permutation and 蠅 recalculated under the same per-pair gene-selection procedure as the observed value, so the null incorporates the gene-selection step. The TCGA per-cancer p
0109| ermutation test additionally holds the identity gene set fixed across permutations (a global HVG panel selected once on the observed grouping); because this fixed-panel null can on
0109| ly deflate the null k_f relative to re-selection, it is anti-conservative, and the corresponding TCGA P-values (all P > 0.9) should be read with this caveat. For the brain atlas, t
0109| he authoritative null is the block-shuffle permutation described under 鈥淢ultiplicative residual model鈥?(10x libraries permuted across regions, per-pair genes re-selected at every p
0109| ermutation; B = 1,000). Empirical P-values use the one-sided upper-tail formula P = (count(蠅_null 鈮?蠅_obs) + 1)/(B + 1), where the +1 pseudocount avoids P = 0; the brain per-pair s
0109| creen instead uses the one-sided lower-tail formula (anomalously low 蠅), with the upper tail reported as a complementary summary. The one-sided default is appropriate because our h
0109| ypothesis is directional: we test whether observed 蠅 exceeds the null expectation, not whether it differs in either direction. Standardized effect size (SES = (蠅_obs 鈭?mean(蠅_null)
0109| ) / sd(蠅_null)) is reported as a non-parametric descriptive statistic complementing the permutation P-value, not a parametric test statistic such as Cohen鈥檚 d. Benjamini-Hochberg (
0109| BH) FDR correction [44] is applied within each dataset; larger-scale analyses are supplemented with non-parametric tests and descriptive statistics.
