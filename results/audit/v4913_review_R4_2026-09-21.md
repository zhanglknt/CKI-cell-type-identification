## Summary

稿件提出 CKI（ω = k_f/k_n），以 housekeeping 基线 k_n 归一化 identity-gene 分歧 k_f。我负责的 TCGA 侧面：五癌种（LUAD/LUSC/LIHC/KIRC/BRCA）bulk RNA-seq 的 NN/TT "pan-cancer reversal"（肿瘤间分歧低于癌旁正常间分歧，ratio 1.10–2.46，四/五癌种 CI 排除 1），其机制定位为分母效应（肿瘤 TT k_n 升高 1.3–3.3 倍），以及 LUAD 驱动突变分层（KRAS 高 ω、EGFR 表观关联由 admixture 解释）。

v49.13 相对 v49.12 的 TCGA 侧变更我已逐项核验：(1) 3,593 样本全量 barcode source-code 审计 + CC-presence ledger；(2) composition post-CC linear 口径（pooled −1.3% [−5.0, +2.3]、ρ=0.364、|Δz| 1.305/1.216）；(3) LUAD whole-tumor label permutation（KW P=0.0001）+ log-ω 敏感性（1.19 [1.12, 1.26]）；(4) pan-cancer 叙事维持。全部变更在 MS/SI/Guide 三处落位一致，且与 ground-truth 输出文件吻合（抽查见下表）。第三轮我提出的 A/B/C 项（dyadic 依赖的推断口径、composition noisy-proxy 的边界声明、CC 样本闭环）均已实质解决。

**总评**：TCGA 部分的方法学诚实度（caliber 声明、noisy-proxy 边界、残余混杂披露、exploratory 定性）已达到本刊方法稿的可接受标准；剩余问题均为报告层面的小疵（Minor），不触及结论。

## Minor issues

**M1. 样本量口径 3,567 / 3,593 / "29 excluded" 三者不能互相推出（建议一句话澄清）。**
MS Results/Abstract 用 3,567；MS Datasets 段写 "3,567 samples entering the pair-level analysis; 29 expression-matrix samples were excluded"（隐含表达矩阵 3,596）；而 CC 审计写 "all 3,593 samples in the pair table"。ground truth（nc49_cc_audit_report.txt）确认 pair table 确为 3,593（571+593+455+836+1138），与 3,567 差 26，与 3,596 差 3——读者无法从现有文本调和这三个数（pair table 中哪 26 个样本未进入 pair-level 分析？）。建议在 Datasets 段或 CC 审计句后补一句口径说明（如 aliquot 去重 / pair coverage 阈值造成的 26 例差异）。

**M2. ex-CC LIHC k_n 区间端点舍入跨过零值。**
MS 写 ex-CC "TT k_n/NN k_n 1.34, 95% CI [1.00, 1.88]"，ground truth 为 1.337 [0.997, 1.880]（nc49_cc_audit_report.txt §2）。把 0.997 舍入为 1.00 会让读者误以为 CI 恰好排除 1；鉴于 MS 同段对全量 LIHC k_n 强调的是 "CI 排除 1"（1.35 [1.02, 1.88]），此处建议直接写 [0.997, 1.88] 或注明 "CI marginally includes 1"。统计结论（null 不变）不受影响，纯属报告精度。

**M3. smoking "joint model" 引用的统计量与模型描述不符。**
MS 写 "adjusting for smoking status—alone or jointly with age, sex, and admixture—…（Δω +13.6, P = 3.3 × 10⁻⁴ in the joint model）"。但 nc49_tcga_luad_smoking.csv 中 +13.635 / P=3.29×10⁻⁴ 对应的是 group + ever_smoke + admix_z 模型（**不含** age/sex）；含 age/sex 的模型（B_smoke_agesex_adj，无 admixture）为 +13.28 / P=1.43×10⁻³；四协变量齐备的模型并未出现。建议把表述改为 "jointly with admixture (and separately with age and sex)"，或补一个全协变量模型。结论不变。

**M4. CC 患者在 Cox / 临床分层队列中的 presence 仅披露、未做剔除敏感性。**
CC ledger（nc49_cc_audit_report.txt §4）记录 32 个 CC 患者在 377 例 LIHC clinical JSON 中，会进入 Edmondson 分层与 Cox 队列（n=304，占 ~10%）。ex-CC 敏感性已覆盖 NN/TT ratio 与 high-purity half，但未覆盖 Cox 与 severity vignettes。鉴于 Cox 主模型为明确 null（HR 1.07 [0.88, 1.31], P=0.48）且 SI Note 9 已把 severity 降级为 denominator-dominated vignettes，风险很低；但细胞系来源样本占生存队列一成，补一个 ex-CC Cox（或在 ledger 中明示不做的理由）即可彻底闭环。

**M5.（提示性，可不改）median k_n ratio 存在两个 pair-table 口径。**
MS 写 "corresponding median ratios 2.18–3.70 in the Supplementary Information"——该值出自 SI Note 8 的 25,306-pair composition 表；而 Suppl. Table 11 口径（nc49_tcga_pancancer.csv，35,306-pair 表）的 median ratios 为 2.08–3.61（LUAD 2.18 vs 2.60 差异最大）。两者均有文档记录、各自正确，但建议 MS 引用处注明 "composition-check pair table"，避免读者用 Table 11 复算时对不上。

**M6.（琐碎）** BRCA NN/TT CI 上界 1.845 在 MS 中写 1.84（截断式舍入，他处均四舍五入）；per-cancer 衰减 MS 写 "−16% ~ +32%" 对应 ground truth −15.9%/+31.7%，可接受。不影响任何解释。

## 专项评估（任务要求逐项）

- **bulk pseudobulk 化合理性声明**：充分。MS Results 开宗明义 "ω here quantifies divergence between tissue states rather than between cell types"；Discussion 进一步声明 bulk 分辨率边界（adjacent-normal ≠ healthy、RNA 质量、tissue-source-site/batch 分层未做 batch-matched 子集、留 GTEx 给未来工作），并以 "tissue-level functional divergence at bulk resolution, pending single-cell or deconvolution-based validation" 收尾。分寸恰当。
- **CC 审计闭环**：审计本身彻底（全量 source-code、唯一异常集、ledger 到每个下游分析），NN/TT 与 high-purity 两条主线均有 ex-CC 敏感性且结论不变；缺口仅在 Cox/severity 的 ex-CC 敏感性（M4）与样本量口径表述（M1）。判定为"实质闭环，报告层面待收尾"。
- **composition "bounds rather than settles" 边界声明**：恰当且诚实。noisy proxy 的测量误差衰减逻辑（attenuation estimates 是真实 composition 贡献的下界）在 MS 与 SI Note 8 中均正确表述；pooled 近零与 per-cancer 异质性（LIHC/KIRC 正衰减 20–32%）未被掩盖，反而明确写出 "pooled near-zero masks this heterogeneity"。这是我上轮要求的核心，处理到位。
- **KRAS/EGFR 去混杂逻辑**：严密。purity（ESTIMATE 代理 + 单调等价声明）、smoking（ever/never + age/sex 变体）、admixture 残差化 KW 三条路径互相印证；EGFR 关联在 purity 调整后全灭（all P>0.4）而 KRAS 双组件保留，对比干净；残余混杂（TP53、IMA、pack-years 缺失 87%→披露）如实声明。M3 的模型标注小疵不影响逻辑。
- **Cox 降 SI 的处理**：合理。主文仅保留一句阴性结果（HR 1.07 [0.88,1.31], P=0.48）用于限定 reversal 的解释边界（"descriptive, not prognostic"），六个模型全量留 SI Table 14；阴性结果未夸大，k_f 边际信号（M4 模型 P=0.072）也未在主文渲染。同意此处理。
