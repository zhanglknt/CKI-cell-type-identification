## Summary

The manuscript presents CKI, a Ka/Ks-inspired heuristic index that normalizes functional divergence (k_f, identity genes) against a housekeeping baseline (k_n). The v49.10 revision is, on the whole, an unusually careful piece of work: limitations are stated quantitatively, nulls are design-matched, and the reproducibility scaffolding (guide, spot-check script, pytest suite, Dockerfile, Zenodo archive) is well above the field norm. Four of the five claimed cross-reference fixes are verified as genuinely corrected. The fifth — the seed-declaration item — is **not** fixed, and the panel's earlier dismissal of it as a "misread" is itself incorrect: the string "seed 20260905" is present in the current SI text and is covered by no declaration in the MS or the Guide. Remaining concerns are documentation-level, not scientific. Recommendation: **Minor Revision**.

## Reproducibility

**Strengths.** The Guide pins a verified environment (Python 3.14.4; numpy 2.4.6; scipy 1.17.1; scanpy 1.12.1; pandas 2.3.3; matplotlib 3.10.9; scikit-learn 1.8.0), data sources with URLs and byte-identical local copies, seeds, per-script outputs, superseded-file warnings (e.g., the `results/superseded/brain_siletti_*_v3.csv` pre-fix files with explicit "must not be used" notes), a 40-assertion spot-check script, 7 pytest regression tests, and a Dockerfile. The MS Methods environment statement matches the Guide's headline versions. The TCGA mapping disclosure (softmax ≡ power transform; linear re-computation as authoritative caliber) is exemplary honesty.

**What is still missing / wrong.**

1. **Guide §2.1 is a dangling reference.** Verbatim: "2.1 Parameter Summary / All parameters used in the reported analyses: / The above parameters, when used with the exact random seed and gene selection procedures described in subsequent sections, should reproduce all values..." — the parameter table itself is absent; "The above parameters" points at nothing. This was flagged in the previous round and is unchanged.
2. **The verified-environment list is incomplete.** It omits at least: `statsmodels` (used for the LIHC Cox models — SI §3.13 "Cox proportional-hazards regression (statsmodels PHReg)"), `seaborn` (listed in MS Methods line 123 but not in Guide §1.1), and the two benchmark dependencies whose versions are stated in the SI but never pinned in the Guide: "PyPI meld 1.0.2" (SI §3.11) and "pyaugur 0.1.0, a pure-Python port of R Augur v1.0.3" (SI Note 14). For a reproducibility-guide document, benchmark dependencies should be pinned where the environment is declared.
3. **No ordered end-to-end run sequence.** The Guide enumerates scripts per analysis section (5.3–5.10) but never gives a single ordered command list from raw downloads to final figures. A reader must reconstruct the execution order (and the supersession rules) from prose. Given the number of superseded files, an explicit run order is close to essential.
4. **Seed declaration gap** (see item v above): notebook 89's seed 20260905 is undeclared.
5. Minor staleness: SI Note 14 says augurpy "is not distributed for Python 3.13" while the declared environment is Python 3.14.4.

## Major concerns

1. **The seed-declaration inconsistency persists and the "misread" dismissal was wrong.** SI Note 2's "(seed 20260905; B = 5,000 on the real data)" contradicts the MS/Guide declaration that the only exceptions to seed 42 are 20260903 (77/78/79) and 777000. Fix is trivial (add notebook 89 to the exception list in both documents), but v49.10 explicitly claims this item fixed, and it is not.
2. **The Reproducibility Guide still is not end-to-end.** The §2.1 parameter summary is a dangling pointer ("All parameters used in the reported analyses:" followed by "The above parameters..."), the pinned environment omits four analysis-critical packages (statsmodels, seaborn, meld, pyaugur), and there is no single ordered run sequence from raw data to figures. For a paper whose central selling point is a reproducible pipeline, these are material.
3. **Abstract length vs journal house style.** 199 words passes this review's ≤200 bar by one word but almost certainly exceeds NC's ~150-word Article abstract limit; it will be returned for shortening. Better to trim now.

## Minor concerns

1. Supp Tables 5–19 exist only as ToC entries and in-note references; only Tables 1–4 have full caption blocks with data-file pointers (SI lines 193–200). Add one-line captions for 5–19.
2. Typography inconsistency: MS line 77 uses "median |Delta z|" (spelled-out) while the same manuscript uses "Δω", "Δk_f" elsewhere (line 49) and "|Δω|" (line 45).
3. Redundancy in SI: "Permutation testing was performed for all four datasets" appears verbatim in §1.5, §3.2, and §3.3.
4. Guide names "Schaum et al., Nature 2018" (Tabula Muris) and "Jones et al., Science 2022" (Tabula Sapiens) while the MS reference list cites the consortia (refs 8, 9) — align.
5. SI Note 14's "Python 3.13" should read 3.14 to match the declared environment.
6. ORCID supplied for only one author.
7. Mixed exponential notation between MS ("7.6 × 10⁻⁴²") and SI ("7.6e-42").
8. Guide §4.4 cites TCGA as "Hutter & Zenklusen, Cell 2018; Liu et al., Cell 2018", neither of which is in the MS reference list (refs 10/11/49 are used instead) — harmless but inconsistent.
