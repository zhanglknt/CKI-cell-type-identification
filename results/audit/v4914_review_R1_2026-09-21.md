## New issues this round

**Major:** none.

**Minor:**

- **m1 (one clause, MS).** The span-matched residual gradient (3.68-fold) is decomposed in SI Note 10 (k_f 1.39 vs k_n 0.33 — i.e., the residual is still predominantly a denominator effect), but the MS sentence "the gradient persists, at reduced magnitude, after both controls" carries no such qualifier. The manuscript's own policy elsewhere is to co-report the decomposition whenever an ω magnitude is quoted (it does so for the full-data and equal-n gradients in the same paragraph). One parenthetical — e.g., "(residual again predominantly k_n-driven: k_f 1.39 vs k_n 0.33; Supplementary Note 10)" — would make the span-matched control consistent with that policy.
- **m2 (one clause, MS).** The donor-stratified-null sensitivity is summarized in MS Results as "leaves the same 3 of 10 classes surviving correction" — true, but the SI-disclosed fact that ependymal cells move *against* the conservative direction (P 0.058 → 0.021, stratified q = 0.052) is invisible in the MS. Since the manuscript otherwise surfaces exactly this kind of boundary behavior, one clause noting the single against-direction class (and that it still does not survive correction) would close the loop at MS level.

Both are transparency-consistency items against the manuscript's own standards; neither affects any conclusion.
