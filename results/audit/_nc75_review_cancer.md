# 审稿意见（reviewer-cancer：癌症基因组学 / TCGA 方向）

**稿件**：CKI_Submission_NC（CKI_Manuscript_NC.docx + CKI_Supplementary_NC.docx，nc73 版投稿包）
**审稿范围**：TCGA 伪 bulk 应用部分的可信度与临床相关性

## 一句话总结

CKI 将 Ka/Ks 的"内部基线归一"思想迁移到转录组比较，其 TCGA 部分报告了一个有趣的 pan-cancer 现象（肿瘤组织 ω 低于癌旁，由 k_n 分母升高驱动）和一个经纯度/吸烟校正后存留的 LUAD KRAS 对比，方法学自检（组成检验、条码审计、线性映射重算、GTEx 外部参照）异常详尽，但核心生物学发现本质上是一个"管家基因基线在肿瘤中失稳"的观察，缺乏生存/预后增量价值的支撑，临床转化前景目前为零。

## 总体评分：6.5 / 10

## NC 中稿率估计：约 25–35%

方法学功底和统计自检达到了 NC 级别的严格性，但 TCGA 部分的生物学结论新颖性和临床相关性偏弱（生存分析为阴性、无与既有标志物的正式对比），且"肿瘤中 HK 锚失稳"的现象用现有数据无法与肿瘤细胞的真实转录调控程序区分，很可能被审稿人判定为"有趣但解释不足"。

## Major Concerns

1. **TCGA 应用与 CKI 核心假设自相矛盾，核心发现更像锚失稳的副产品而非生物学发现。** 正文自己承认"在疾病或强扰动背景下锚本身会漂移"（Introduction 及 Note 1）。Pan-cancer 反转（NN ω > TT ω）被分解为 TT k_n 升高 1.3–3.3 倍——即肿瘤中管家基因表达分布更不稳定。这至少有三种解释：(i) 肿瘤细胞 HK 基因失控（作者引用 ref 38）；(ii) 肿瘤微环境组成差异（Note 10 显示 TT 对内组成差异显著更大，|Δz| 1.3–1.5 倍）；(iii) RNA 质量/缺血等预处理差异。作者用四 marker-panel 回归、高纯度半区、GTEx 外部参照排除了大部分组成解释，但 LIHC（+44%）和 KIRC（+20%）的逐癌种组成衰减很大、pooled −0.9% 掩盖了异质性；GTEx 跨队列技术位移本身达 1.8–2.3 倍，而"健康≈癌旁"的相似性恰在此容差内（作者也自认 tentative）。"肿瘤特异性 HK 失稳"这一机制结论的置信度被作者自己的数据打了折扣，标题级表述应进一步收敛。

2. **"细胞受选择"的演化类比在肿瘤语境下存在过度解读风险。** ω 命名与 Ka/Ks 直接对应（图 1a），但管家基因并非机制上中性（作者已声明 heuristic），而在肿瘤中 HK 基因恰恰是已知会失调的集合——选择类比在最需要它的应用场景里失效。KRAS 突变肿瘤 ω 升高被解读为"更高的组织态发散"，但其 73% 由更低的 k_n 承载，功能成分（k_f KRAS > EGFR，P_Holm = 0.015）只是边际贡献；且该解读与增殖、代谢应激、TP53 共突变（作者承认未校正）等混杂完全未区分。建议全文避免在 TCGA 部分使用任何"选择/selection"语汇。

3. **临床相关性证据几乎为零，且与既有标志物的增量价值未被评估。** 唯一的生存分析是 LIHC Cox（ω HR/SD 1.08 [0.88, 1.33], P = 0.467，含分期），明确阴性；无任何癌种做分期/分级与 ω 的预后关联（LIHC Edmondson 与 BRCA PAM50 的"severity gradients"被作者自己证明为分母假象并降级为 vignettes，Note 5）。文章没有回答一个 NC 编辑必然要问的问题：相比 PAM50、增殖指数、TP53 突变状态、或 ESTIMATE 纯度本身，CKI 增加了什么？KRAS–WT 对比在校正纯度与吸烟后仍显著（adjusted P = 0.009/0.029），这是 TCGA 部分最强的结果，但它只说明 ω 携带了突变状态相关信息，而这种信息用 k_f 或常规差异表达也能获得——没有做与现有 LUAD 转录组分型（如 Truong 等的三个 LUAD 亚型）的对比。摘要中"stratifies lung-adenocarcinoma driver classes"的表述强于证据。

4. **TCGA 置换检验口径中身份基因未在置换内重选（"TCGA fixed-panel excepted"）。** 其余数据集 identity 基因逐迭代重选以吸收 circular selection 造成的 k_f 系统性膨胀；TCGA 用固定 panel 意味着 k_f 保留了选择膨胀偏倚。虽然标签置换下观察值与 null 共享同一 panel、比值意义上的影响可能有限，但 KRAS 对比落在置换下限（P ≤ 0.001）时，膨胀偏倚对 SES 与经验 P 的净影响未被量化。此外 KRAS 组 P = 7.8 × 10⁻⁷ 的 Kruskal-Wallis 是名义 P，三组严重度分析×三度量的 post-hoc k_f 控制均无多重校正（作者在 Note 5 承认）。

5. **配对结构的信息浪费与 TT 对子抽样。** 每肿瘤仅参与中位 4–11 对，TT 上限 2,000 对/癌种做种子抽样——虽然 cluster bootstrap 处理了依赖结构，但 3,535 例样本仅支撑约 34,828 对，且驱动突变分析中 EGFR 组仅 61 例（75 个标签中 62 匹配、剔 2 个双突变），多重匹配损失（13 个 EGFR 标签未匹配矩阵）值得说明原因。双突变 KRAS+EGFR 样本被直接剔除而非单独报告，LUAD 中这类共突变的生物学意义不应被方法学决定。

## Minor Concerns

- 结外（kidney）GTEx n = 28 且已知自溶问题，KIRC 部分应更显著地降级，而非以"exception"带过。
- GTEx V8 与 TCGA 处理管线不同（UTR 标注、workflow 版本），"identical k_n pipeline"只指下游，正文应明示。
- 32 个细胞系来源样本的条码审计（Methods 5.3）做得好，值得肯定；但 5.12 的 ex-CC 对数表述（34,828 vs 35,306 vs 3,593 barcode）较绕，建议列表化。
- softmax 对 log2(TPM+1) 等价于 1.4427 次幂变换此前未披露、现已全量重算——处理得当，但建议在正文（而非仅 SI 1.7）一句话披露，因为这是所有 TCGA 数值的前处理。
- 图 3a 双轴刻度独立（蓝/琥珀），审稿人和读者容易误读两个 ratio 的可比性，建议在图注加显著提示。
- "per-tumor ω was not associated with survival" 放在 TCGA 结果段落中部，建议升格为明确的小标题或在 Discussion 中正面讨论阴性意义（诚实但值得凸显——它约束了临床转化的想象空间，作者没有夸大这点值得肯定）。

## 强项

1. **统计自检的完备程度远超同类投稿**：组成衰减的样本级 cluster bootstrap、逐癌种异质性披露、GTEx 外部参照、线性映射全量重算、条码审计排除细胞系样本、置换+参数双口径验证调整模型——每一步都先于审稿人指出自己的弱点。
2. **分解优先（decomposition-first）的解读纪律**：作者主动证明 LIHC/PAM50 梯度是分母假象并降级结论，这种自我否定式分析增强了 KRAS 结果（同时通过 k_f 与 k_n 双通道）的可信度。
3. **KRAS–WT 对比是 TCGA 部分最扎实的结果**：效应量明确（adjusted log-ω ratio 1.19 [1.12, 1.26]），经纯度、吸烟、年龄、性别及 B = 10,000 整瘤置换检验存留，且 EGFR 假信号在校正后被诚实清除。
4. 阴性结果（生存、Hallmark 富集 q ≥ 0.24）如实报告，无 cherry-picking 迹象。

## 必答问题（Revise 意见）

1. 请将 pan-cancer 反转的机制表述从"tumor-specific HK dysregulation"进一步收敛：在 GTEx 跨队列位移（1.8–2.3 倍）的容差内，"健康≈癌旁"的结论有多稳健？请给出 healthy/adjacent 比值的敏感性分析（例如按 GTEx 平台亚队列分层）。
2. KRAS 对比：请报告 (a) 置换内固定 panel 对经验 P/SES 的影响（至少用 leave-pair-out panel 重跑 null 验证结论）；(b) TP53 共突变校正后的 KRAS–WT 效应；(c) 与既有 LUAD 转录亚型分类的 AUC/一致性对比，以支持"stratifies driver classes"超出常规 DE 分析的增量价值。
3. 请正面陈述 CKI 在肿瘤语境下相对 PAM50/增殖指数/ESTIMATE 的定位：作者是否同意 CKI 当前在 TCGA 中是描述性/机制性工具而非预后工具？若是，请修改摘要与 Discussion 的措辞。
4. LIHC Cox 的 cox.zph GLOBAL P = 0.023 提示比例风险违背，请报告违反时间依赖的处理（如分段 Cox）后 HR 是否仍稳定（尽管 P = 0.467，结论大概率不变，但需完备）。
5. 驱动突变标签匹配：13 个 EGFR 标签未能匹配表达矩阵的原因是什么？是否引入选择偏倚？
6. 建议在正文（非仅 SI）披露 softmax-as-power-transform 问题与 ex-CC 排除对主结论的数值影响。

## 结语

TCGA 部分是一项诚实、自检严密的描述性分析，最可信的产出是"肿瘤 HK 基线失稳 + KRAS 突变态在 ω 与 k_f 上的可分离信号"。以当前证据，它支撑不了一篇以临床转化为卖点的论文，但作为方法学论文的"domain stress test"章节是合格甚至优秀的。若作者接受降级表述并补齐 KRAS 部分的增量价值验证，该部分不构成拒稿理由；NC 层面的成败更取决于单细胞/脑图谱部分与方法的整体新颖性。
