# Review — Nature Communications (Reviewer R5: Computational Reproducibility & Software Engineering)

**Manuscript:** CKI: A Cell-type Identity Index for Quantifying Baseline-Normalized Transcriptomic Remodeling (nc59 + code v0.5.5, submission package v50, 2026-10-03)
**Reviewer expertise:** packaging, CI, documentation, data/code availability, computational reproducibility
**Date:** 2026-10-03

---

## Summary

The authors provide a Python package (`cki`, v0.5.5), a 30-page Computational Reproducibility Guide (Supplementary Methods), a Dockerfile, a pip-freeze lock file, a CI workflow, and a GitHub+Zenodo archival chain. I independently verified the submission: extracted both DOCX files with python-docx, re-ran the full test suite (29 passed), re-ran the authors' `scripts/spot_check.py` (all assertions passed), test-ran `run_all.py --dry-run`, resolved both Zenodo DOIs, verified 5 MANIFEST SHA-256 checksums, and audited 31 file paths cited by the Guide against the repository. The engineering standard is far above typical submissions — however, the Reproducibility Guide was not fully re-versioned for the v0.5.5 release it ships with, and the repository README carries several stale numbers from earlier rounds. These are documentation-integrity issues in precisely the documents a reproducer reads first.

## Strengths

1. **Executable verification layer that actually works.** `python -m pytest tests/ -q` → 29 passed (22 smoke + 7 reference-value; exactly the split claimed in Guide §7 checklist). `scripts/spot_check.py` recomputes 46 headline numbers from the authoritative result files → ALL CHECKS PASSED, including TCGA ex-CC ratios, Strong 39/31/q = 0.520, internal baselines 9.73/7.67, and the nc50 microglia AUC = 1.00 claims.
2. **Availability statements verified externally.** GitHub tag v0.5.5 exists; Zenodo concept DOI 10.5281/zenodo.20405458 resolves and its latest version is v0.5.5; version DOI 10.5281/zenodo.23104178 resolves to the v0.5.5 record (published 2026-10-02, 1.6 GB archive). MIT LICENSE present; pyproject `requires-python >=3.10` matches the Code availability text and the CI matrix (3.10–3.14).
3. **Environment pinning is real, not decorative.** `requirements-lock.txt` is a genuine pip-freeze of the verified env; the claimed analysis interpreter (Python 3.14.4) exists on disk (`cki_env/pyvenv.cfg`, version 3.14.4); the Dockerfile (`python:3.14-slim`, lock-file install, import + HRT-Atlas sanity CMD) is minimal and correct.
4. **MANIFEST integrity.** All 5 spot-checked SHA-256 checksums (manuscript, guide, SI, figure1, Supplementary_Fig_7) match the shipped files byte-for-byte; `results/` copies of the two DOCX are byte-identical to the submission copies.
5. **Guide-to-repository path accuracy is high.** 30 of 31 audited paths exist, including all authoritative results (brain_bs_null_*, nc52_tcga_*, mouse_splithalf_v44, nc50_*), the bundled probeMap, and the fixed-exception seed scripts (seeds 20260903/777000/20260905 confirmed in notebooks 77/78/79/89 exactly as documented in Guide §1.4).
6. **Supplementary cross-references survived the renumbering.** Guide → SI pointers verified: Note 10 (TCGA composition) ✓, Note 14 (brain set-level enrichment) ✓, Supplementary Table 2 (linear-normalization robustness) ✓, SI §1.7 (probability-mapping robustness) ✓, SI §3.9 (Parameter Justification) ✓, SI §5.12 (TCGA per-sample statistics, contains the Monte-Carlo ±0.01–0.02 statement) ✓. Manuscript cites Supplementary Figs. 1–14 monotonically; MANIFEST ships all 14 PDFs; SI contains Notes 1–16 and Tables 1–19 as declared in Data availability.
7. **Package quality.** Clean module layout (core/bootstrap/blocknull/gene_sets/preprocess/species/utils), substantive docstrings including an explicit three-convention numerical-guard policy in `core.py`, `run_all.py --dry-run` executes and validates data prerequisites, honest README documentation of the `bootstrap_test` naming and of the preset-vs-default discrepancy (`preset="manuscript"`).

## Major comments

**M1. The Reproducibility Guide is versioned for the wrong release (v0.5.4, not v0.5.5).**
Location: CKI_Reproducibility_Guide_NC.docx, §1.2 ("Version: 0.5.4 (editable install from project root)"), §6 ("reference_results/ in tag v0.5.4"), §7 checklist item 1 ("Install CKI v0.5.4"). Verified directly in the DOCX via python-docx: three occurrences of 0.5.4, zero of 0.5.5.
Why it matters: the manuscript's Code availability and the Zenodo archive pin v0.5.5; the Guide tells the reproducer to install v0.5.4 and to trust a results mirror at tag v0.5.4. Because v0.5.5 changed supplementary content (monotone SF renumbering, SF3 microglia figure), a reader following the Guide checks out a tree whose figure numbering and reference results differ from the submission. Compounding this, the word "Zenodo" appears nowhere in the Guide — the only archival pointer a reproducer gets is the GitHub URL. Fix: bump all version strings to 0.5.5 and add the concept/version DOIs to §1.2. Severity: **Major** (wrong-release instructions in the primary reproducibility document; trivial to fix).

## Minor comments

**m1. Guide cites a nonexistent script.** §4.2 (Tabula Sapiens): "applied downstream in notebooks/13_phase35_human_pairs.py" — no such file exists anywhere in the repository (the phase-35 script present is `notebooks/13_phase35_method_comparison.py`). The phantom name has persisted since the v43 build scripts, which only assert that the string appears in the Guide text (self-referential check). Severity: Minor — the real script exists, but the citation misleads.

**m2. README carries stale numbers from superseded rounds.**
- Line ~173/180: `omega_cal = omega / 6.67` and "empirical baseline of omega = 6.67" — superseded by 7.70 [6.38, 9.82] since v44 (Guide §5.8e explicitly marks 6.67 as superseded).
- Line ~77: `docker build -t cki:0.5.0` (current: 0.5.5).
- Line ~188/215: "Submitted to Genome Biology (2026)" — the venue is now Nature Communications.
- Line ~165: "(see manuscript Note 3.19)" — the SI contains sections 3.1–3.13 only; Note 3.19 does not exist.
Severity: Minor individually; collectively they signal the README was not re-proofed for this submission.

**m3. No compute-budget disclosure.** Neither the Guide nor the README states expected wall-clock runtimes. Guide §1.3 gives RAM (≥32 GB) and disk (≥5 GB) but nothing on time. The heaviest items (block-shuffle null: B = 1,000 × 31,764 pairs; TCGA `06_phase34_v2.py` on a ~5 GB TPM matrix; B = 10,000 whole-tumor permutation in §5.13d) are multi-hour to multi-day jobs on a workstation. NC's reproducibility expectations are better served by a small table of per-pipeline runtimes on the authors' hardware. Severity: Minor.

**m4. MANIFEST internal header inconsistency.** `MANIFEST_v50.txt` titles itself "CKI Submission Package v49 (Nature Communications)" and "tag: v0.5.x". The file list and checksums are correct (verified), but the header text is one round stale. Severity: Minor (cosmetic, but this is the file a handling editor opens to check package completeness).

**m5. Residual legacy naming in figure outputs.** Guide §5.7f outputs the Kang demo figure as `results/figures_submission/Supplementary_Figure_S13.pdf`, while under the monotone renumbering that figure is now Supplementary Fig. 4. The file exists and the mapping is explained in-text, so reproduction is unaffected; consider renaming outputs to the final SF numbering to close the loop. Severity: Minor (cosmetic).

**m6. CI does not exercise the reference-value tests.** `.github/workflows/ci.yml` runs `pytest tests/ -v` on a fresh checkout where `results/` is absent, so the 7 reference-value tests auto-skip (by design) and CI effectively covers only the 22 smoke tests. Consider a CI job that downloads the Zenodo reference-results subset and runs the full 29. Severity: Minor (suggestion, not a defect).
